# 11 — 用户真实试玩与全量验收

**What to build:** 由用户决定是否开展真实浏览器完整测试，实际检查画面、声音与体验。

**Blocked by:** 10 — 完整展示版集成与交付

**Status:** ready-for-human

**负责人：** 用户。此票不属于开发完成的自动验收，等待用户选择是否执行全量真实测试。

- [x] 用户已明确真实测试交由人工执行。
- [ ] 按人工清单执行常规通关、积怪失败、无尽、重开、地图、声音与窗口检查。
- [ ] 双模式：菜单切换保留各自对局；保卫战四路轮攻、漏怪扣耐久、清场补给、核心归零、通关后切换返回战报并进入无尽；地图和建造浮层在真实视口中核对。
- [ ] 四模式补充：采集点选择／切换／耗尽／主动撤离；风暴状态／双路／过载脉冲／六分钟生存与无尽；四份对局切换和任务抽屉实际操作，确认主地图不被挤动。
- [ ] 记录环境、截图、复现步骤和最终人工结论。

当前运行版本已将旧采集／风暴替换为护送／迷宫，上方旧检查项仅作历史记录。当前还需人工：

- [ ] 护送：启程／停车、两次停靠、维修、选择升级塔搬迁、3秒停机反馈、追兵近战、到站或载具损毁。
- [ ] 迷宫：连续任意位置布塔／路障、路线预览与怪物实际改道、堵路拒绝、拆障、出口失守、12波与无尽。
- [ ] 四份对局切换／战报／重开、实际视口与浮层不挤图、动态路线可读性、音效和操作手感。
