# 31 — 军团双战场与自动接战

**What to build:** 建立两份独立战场／国王状态、六种完整守军数值和自动接敌，锁定双阵地几何、战后复原与同步胜负。

**Phase:** 3／军团

**Blocked by:** 无（按阶段优先级调度）

**Status:** ready-for-agent

**进度：** 尚未开始。本票描述就绪，实际开工须等待前置完成；不能因计划已生成而标记done。

**规则：** [模式设计](../../../docs/modes/legion-duel.md)；[总实施计划](../../../docs/war3-modes-implementation-plan.md)。

## 完成条件

- [ ] 单位有生命、移速、射程、仇恨和体积，站位影响接敌，不能仍是不可伤害的固定塔。
- [ ] 漏怪与国王继续战斗，国王有实际反击，血量不在波后恢复。
- [ ] 双边战斗按同一时钟推进，同步收集伤害；同一模拟步国王同时死亡判平局。
- [ ] 守军战后复原原阵型／生命／等级；补齐六兵种、国王和基础波次配置。

## 验证

两份状态隔离、前后排差异、王战、战后复原、暂停及同时致命场景；确认原四模式回归。

原素材只读。真实浏览器完整体验、声音和主观难度仍由用户验收，不在自动结果中代勾。
