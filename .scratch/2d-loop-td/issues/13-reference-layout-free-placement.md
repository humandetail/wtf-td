# 13 — 参考布局与区域自由建造

**What to build:** 按用户参考图组织外环、内环、中心十字和连接通道，取消固定塔位。玩家选定工事后，在可建造区域任意坐标放置，预览和实际建造使用一致的规则。

**Blocked by:** 10 — 完整展示版集成与交付

**Status:** in-progress

- [ ] 外环、内环、中心枢纽和连接通道进入实际路网；参考图及旧版本保留。
- [ ] 连续坐标建造，无预设点或隐藏吸附；完整占地避开道路、枢纽、边界及已有建筑。
- [ ] 跟随指针显示绿色区域、工事虚影、占地和非法原因；可连续建造并取消。
- [ ] 建筑独立编号，升级、出售、重建及重开正确，失败不扣款也不分配编号。
- [ ] 更新术语、规格与操作说明，并检查正常经济的常规通关路线。
- [ ] 交付地图及区域预览，完成类型、资源、公开对局和独立代码检查；真实试玩仍由用户进行。
