# 02 — 独立交付循环圈桌面与手机界面

**What to build:** 玩家可以用鼠标或触控完成抽卡、部署、出售、出装、挑战、打金及进入无尽。界面先接约定会话与代表状态，正式会话联调在 12 验收。

**Blocked by:** 01 锁定循环圈会话契约和试玩样例

**Status:** done

**执行安排** — 唯一 UI 子 Agent 负责本票，并协助 12 的 UI 联调修复。主 Agent 同时推进玩法；本票仅等待 01，可用契约 ID 与占位图核对界面。

- [x] 展示三选一、留牌与卖卡、人口和回收价。完成部署预览和确认，非法落点、满人口、取消或连续触碰不会多消费。候选和卡包的跨波状态可从界面复现。
- [x] 塔详情显示经验、已解锁和待解锁技能、三槽、组件／成装库存、拆装与合成，以及脱战剩余时间和失败原因。
- [x] 预告和战场显示两波真实配置会用到的字段、积怪与待投放数、挑战开放和计时、金币伤害／奖金、G04 转场、结算和无尽入口。隐藏循环圈旧科技、付费升级和专精入口。
- [x] 代表状态覆盖鼠标、窄屏、触控确认、横屏及拖拽缩放。抽屉开关保持战场视野，选中、退出和焦点回归明确。保留其余六种模式的入口和控件行为。

交付证据见[循环圈改版交付记录](../../../game/qa/loop-rework-delivery.md)。
