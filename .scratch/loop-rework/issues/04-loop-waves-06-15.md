# 04 — 完成中段双盾、隐匿和治疗战斗

**What to build:** 把可玩对局扩到第 15 波。玩家可以用新塔应对隐匿、两种护盾、加速、分裂和带读条的治疗。

**Blocked by:** 03 跑通抽卡养塔与第一个 Boss

**Status:** done

- [x] 按主表接入第 6–15 波配比，包括镇响铜铃、回生灵童和对应人口／品质提升。两波预告取自实际投入队列。
- [x] 为本段接入能实战反制的塔卡及 1／3／5 级技能，覆盖显形、快攻、耐久破盾、治疗干扰和读条打断。每种难点至少能演示两套应对。
- [x] 按技能结算次数盾、耐久盾、隐匿、减益、抑疗与控制免疫。分裂子体占容怪，无独立收益，清完才结算该波奖励。
- [x] 用合法落点、默认资源和正式命令跑到第 15 波，确认状态在倍速、暂停和怪物跨波时可复现。
