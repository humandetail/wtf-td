# 环界 · 循环圈塔防

单人浏览器塔防：科技防御单位迎战东方玄幻敌人。地图以外环、内环和中心枢纽为骨架，横纵连接通道构成互通的路网。普通怪物和 Boss 从中心独立随机选择四个方向出发，在每个交叉点随机选择前方分支，不原地掉头，拐角自动转弯。所有绿色有效区域均可自由放置工事，位置连续且不吸附网格。漏过的敌人会与下一波叠加；场上存活怪物达到容怪上限时失败。

## 运行

在项目根目录使用支持 ES Modules 的现代 Node.js 和 npm：

```sh
npm install
npm run dev
```

打开 <http://127.0.0.1:4173/game/>。服务仅监听本机；访问根路径会跳转到游戏。可通过 `PORT=4174 npm run dev` 更换端口。按 `Ctrl+C` 停止。

请通过 HTTP 服务运行，不要双击 HTML。运行时必须保留同级 `outputs/` 原素材目录及 `game/` 新游戏目录的完整结构。代码使用原生 HTML、CSS、JavaScript 和 Canvas，没有生产依赖；TypeScript 仅作为开发检查工具安装。首次启动需要浏览器加载原图，加载完成后进入菜单。

## 操作

- 点击“开始布防”进入对局，首波前有 18 秒准备时间。
- 先选右侧工事，再在绿色区域任意放置，可连续建造。绿色预览表示可放置，红色表示无效并提示原因。道路、中心枢纽、越界及与已有工事重叠的位置不可建造。右键、`Esc` 或“取消建造”退出建造模式。卡片显示价格与用途。
- 右侧科技区研究部署科技以增加容量和解锁塔种类，研究强化科技以开放升塔上限；全局一次一项，费用开始时扣除，倒计时结束才生效。未完成可取消并全额退款。
- 退出建造模式后，点击已建造工事查看属性、射程、升级费用和出售回收值。金币不足或无法操作时会有提示。
- 键盘操作：选择工事后焦点进入战场；用方向键移动虚拟光标，每次 16 像素，按住 `Shift` 每次微调 4 像素；按 `Enter` 部署，退出建造模式后可在光标处选择已有工事。鼠标移动不吸附网格。`Tab` 在按钮间移动，`Enter` 或空格激活按钮。战场中空格暂停 / 恢复，`Esc` 取消选择。
- 顶栏可暂停、切换倍速、静音或返回主菜单。切换到其他浏览器标签页会自动暂停，返回后手动恢复。
- 菜单的“玩法说明”介绍完整规则。结算后可重新开始；通关后可保留防线进入无尽模式。

音效在首次用户交互后解锁，使用 Web Audio 现场合成，不需要音频文件。静音会立即停止当前声音及已排队的尾音。浏览器禁用音频时仍可运行游戏。

## 当前对局规则

| 项目 | 数值与规则 |
| --- | --- |
| 初始金币 | 400 |
| 容怪上限 | 80，达到即失败 |
| 常规关卡 | 20 波，每 5 波加入一名首领 |
| 波次节奏 | 首波准备 18 秒，之后每 26 秒投入新波；不等待清场 |
| 建造 | 有效区域自由放置，部署科技逐级开放 3／6／9／12 类、4／8／12／20 座 |
| 升级 | 开局最高 1 级；强化科技 1–4 级开放塔 2–5 级，逐塔付费升级 |
| 出售 | 返还累计投入的 70%，向下取整 |
| 通关 | 常规波次全部投入，且所有剩余敌人被击杀 |
| 无尽 | 通关结算后选择进入，保留已有塔与金币 |

输出塔负责自动攻击；减速、定身、群攻与连锁各有用途。雷达提升附近攻击塔的伤害与射程，维修臂提高攻速，无人机补给站定期提供金币，工程路障提供区域减速。道路不会被封堵，建筑没有生命值。相同种类的辅助光环不叠加；首领的定身持续时间较短。具体单位价格、属性及成长见 `catalog.js`，对局规则见 `engine.js`，建造区域与路网见 `geometry.js`。

部署科技升至 1／2／3 级分别花费 120／300／600 金币，耗时 12／20／30 秒；强化科技升至 1／2／3／4 级分别花费 100／200／350／550 金币，耗时 10／15／20／25 秒。两条科技独立且必须逐级研究，没有波次门槛；研究不需要建造研究所，也不占塔数量。出售塔会立即释放容量。

研究随暂停和返回菜单冻结，倍速同步加速；通关结算冻结未完成研究，进入无尽后保留科技并继续剩余时间。重开把两项科技恢复 0 级并清空研究任务。

当前不保存对局进度。刷新页面或重新开始会离开本局；返回菜单会暂停本局，点击“继续布防”可以回来。无账号、存档和排行榜。

## 文件与素材

- `index.html`、`styles.css`：菜单、战场操作面板、帮助与结算。
- `main.js`、`render.js`：交互、资源加载与 Canvas 表现。
- `engine.js`、`catalog.js`、`geometry.js`、`research.js`：对局、单位配置、地图几何及科技解锁／费用／时间。
- `audio.js`：本次原创的短音效合成，覆盖发射、命中、击杀、建造、升级、出售、波次、胜利、失败。
- `assets/maps/v2/`：保留的四防区地图素材；当前路网使用 `assets/maps/v3/`；`v1/` 保留初版图片、源文件和旧路线。原有地图根目录图片同样保留。
- `assets/original-assets.sha256.json`：开发前原素材内容基线。
- `../outputs/`：只读的原始素材与原清单；游戏直接引用其中的单位方向图、道具与特效。原 `../work/` 源文件与备份也纳入完整性保护，不通过游戏服务公开。

## 检查与验收边界

静态检查可以单独运行：

```sh
node scripts/check.mjs
```

此检查核对原素材全部 808 个文件的清单与 SHA-256、原清单引用、地图 PNG 尺寸与透明叠图、必需 UI ID、游戏及脚本语法。它不运行浏览器，不播放声音，也不证明地图效果和难度平衡已通过。

项目另有 `npm run typecheck` 与 `npm test`。后者通过公开对局接口检查研究、建造、战斗及正常经济通关，不操作浏览器或播放声音。最新执行结果见 `qa/verification.md`。

**真实浏览器完整对局、截图、实际试听及地图 / 平衡验收均由用户进行，当前状态为待验收。** 请按 `qa/manual-checklist.md` 记录浏览器、结果与证据。自动化或规则检查通过不能代替上述人工验收。
