# 环界 · 循环圈塔防

单人浏览器塔防：科技防御单位迎战东方玄幻敌人。地图以外环、内环和中心枢纽为骨架，横纵连接通道构成互通的路网。普通怪物和 Boss 从中心独立随机选择四个方向出发，在每个交叉点随机选择前方分支，不原地掉头，拐角自动转弯。所有绿色有效区域均可自由放置工事，位置连续且不吸附网格。漏过的敌人会与下一波叠加；场上存活怪物达到容怪上限时失败。

## 运行

在项目根目录使用支持 ES Modules 的现代 Node.js 和 npm：

```sh
npm install
npm run dev
```

打开 <http://127.0.0.1:4173/game/>。服务仅监听本机；访问根路径会跳转到游戏。可通过 `PORT=4174 npm run dev` 更换端口。按 `Ctrl+C` 停止。

请通过 HTTP 服务运行，不要双击 HTML。运行时必须保留同级 `outputs/` 原素材目录及 `game/` 新游戏目录的完整结构。代码使用原生 HTML、CSS、JavaScript 和 Canvas，没有生产依赖；TypeScript 仅作为开发检查工具安装。启动时会先打开可用界面，美术在后台载入。

## 操作

- 点击“开始布防”进入对局。在循环圈打开免费起手 SR、从卡包部署之后，才开始首波 30 秒倒计时。
- 默认显示大地图。循环圈用底部“卡牌”在卡铺购卡并从卡包部署，其他相关模式用“建造”选工事。选定后面板自动收起。绿色预览表示可放置，红色表示无效并提示原因。道路、中心枢纽、越界及与已有工事重叠的位置不可建造。右键、`Esc` 或“取消建造”退出建造模式。卡片显示价格与用途。
- 循环圈用底部“装备”购买散件和查看制作书。使用科技规则的其他模式可从“科技”研究部署和强化。
- 退出建造模式后，点击已建造工事打开详情抽屉，查看属性、射程、升级费用和出售回收值；收起按钮或 Esc 可关闭抽屉并恢复焦点。金币不足或无法操作时会有提示。
- 键盘操作：选择工事后焦点进入战场；用方向键移动虚拟光标，每次 16 像素，按住 `Shift` 每次微调 4 像素；按 `Enter` 部署，退出建造模式后可在光标处选择已有工事。鼠标移动不吸附网格。`Tab` 在按钮间移动，`Enter` 或空格激活按钮。战场中空格暂停 / 恢复，`Esc` 取消选择。
- 顶栏可暂停、切换倍速、静音或返回主菜单。切换到其他浏览器标签页会自动暂停，返回后手动恢复。
- 主菜单和对局菜单的“作战手册”可查看玩法规则、循环圈塔卡与装备。对局中打开手册会暂歇，关闭后继续。结算后可重新开始；通关后可保留防线进入无尽模式。

音效在首次用户交互后解锁，使用 Web Audio 现场合成，不需要音频文件。静音会立即停止当前声音及已排队的尾音。浏览器禁用音频时仍可运行游戏。

## 循环圈对局规则

- 开局 80 金和一包免费随机 SR。部署起手塔后开始 30 秒倒计时。R／SR／SSR 包价格 120／300／750 金，价格决定品质上限，连续两次未从 SSR 包开出 SSR 后下一包保底。
- 敌人沿环路持续游走，积怪达到 60 即失败。常规 50 波，每五波一名首领。开局即有 100 人口，R／SR／SSR 各占 5／20／20，无尽沿用。清完第 50 波可进入无尽，继承本局塔、卡、装备和金币。
- 战场情报提前两波列出首领机制和反制建议。击杀第 5／15／25／35／45 波的首领会开启打金事件，按对金币怪造成的伤害结算。
- 卡包里选中塔卡时，出怪倒计时、战斗和金币结算会一起暂停。收起卡牌、取消选中或点击部署后继续。
- 塔依靠击杀经验升级，1／3／5 级解锁技能。R 塔 3 个装备槽，SR／SSR 塔 6 槽。主力到 5 级后，用对应的满级 R 塔资格和 180 金突破。第 15 波开放五换一的定向 R 卡兑换。
- 基础商店卖散件，制作书显示各级卷轴及缺件。橙装需要已突破的 SR／SSR 塔。带主动技的装备默认自动，可在塔槽切换手动。

详细机制见[塔卡与怪物设计](../docs/loop-towers-and-enemies.md)和[装备图标总览](assets/modes/loop/equipment-source/overview.png)。其余模式的规则独立。

当前不保存对局进度。刷新页面或重新开始会离开本局；返回菜单会暂停本局，点击“继续布防”可以回来。无账号、存档和排行榜。

## 文件与素材

- `index.html`、`styles.css`：菜单、战场操作面板、帮助与结算。
- `main.js`、`render.js`：交互、资源加载与 Canvas 表现。
- `engine.js`、`catalog.js`、`geometry.js`、`research.js`：对局、单位配置、地图几何及科技解锁／费用／时间。
- `audio.js`：本次原创的短音效合成，覆盖发射、命中、击杀、建造、升级、出售、波次、胜利、失败。
- `assets/maps/v2/`：保留的四防区地图素材；当前地图使用 `assets/maps/v5/scene.png` 的完整玉石封印庭院，道路与地块同图绘制；v3/v4 地图和源文件保留；`v1/` 保留初版图片、源文件和旧路线。原有地图根目录图片同样保留。
- `assets/original-assets.sha256.json`：开发前原素材内容基线。
- `../outputs/`：只读的原始素材与原清单；游戏直接引用其中的单位方向图、道具与特效。原 `../work/` 源文件与备份也纳入完整性保护，不通过游戏服务公开。

## 检查与验收边界

静态检查可以单独运行：

```sh
node scripts/check.mjs
```

此检查核对原素材全部 808 个文件的清单与 SHA-256、原清单引用、地图 PNG 尺寸与透明叠图、必需 UI ID、游戏及脚本语法。它不运行浏览器，不播放声音，也不证明地图效果和难度平衡已通过。

项目另有 `npm run typecheck` 与 `npm test`。后者通过公开对局接口检查研究、建造、战斗及正常经济通关，不操作浏览器或播放声音。最新执行结果见 `qa/verification.md`。

**真实浏览器完整对局、截图、实际试听及地图 / 平衡验收均由用户进行，当前状态为待验收。** 请按 `qa/manual-checklist.md` 记录浏览器、结果与证据。自动化或规则检查通过不能代替上述人工验收。
