# 环界 · 循环圈塔防

单人浏览器塔防：科技防御单位迎战东方玄幻敌人。地图以外环、内环和中心枢纽为骨架，横纵连接通道构成互通的路网。普通怪物和 Boss 从中心独立随机选择四个方向出发，在每个交叉点随机选择前方分支，不原地掉头，拐角自动转弯。所有绿色有效区域均可自由放置工事，位置连续且不吸附网格。漏过的敌人会与下一波叠加；场上存活怪物达到容怪上限时失败。

## 运行

在项目根目录使用支持 ES Modules 的现代 Node.js 和 npm：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:4173/game/>。服务仅监听本机；访问根路径会跳转到游戏。可通过 `PORT=4174 npm run dev` 更换端口。按 `Ctrl+C` 停止。

请通过 HTTP 服务运行，不要双击 HTML。运行时必须保留同级 `outputs/` 原素材目录及 `game/` 新游戏目录的完整结构。公开版使用原生 HTML、CSS、JavaScript 和 Canvas；本地 3D 入口按需加载 WebGL 模型库。启动时会先打开可用界面，美术在后台载入。

### 循环圈 3D 本地试玩

运行 `npm ci` 和 `npm run dev` 后，打开 [3D 对局](http://127.0.0.1:4173/game/?view=3d)。本机入口使用 `~/Downloads/环界模型库`。塔、怪物和特效在出场时读取模型，载入期间显示原有表现。局内菜单可以在同一局切换 2D 和 3D，或者打开模型库。3D 战场的底部指挥区提供已部署塔、单位详情和命令。

[本地模型库](http://127.0.0.1:4173/game/local-3d/models.html)可以按文件名或目录搜索，预览模型、切换动作，并为指定单位或战斗特效设置外观。分配保存在当前浏览器中，也能恢复项目默认值。缺贴图的条目在预览中使用占位贴图，并列出待补文件。

在项目根目录运行 `python3 scripts/import-models.py` 可从 `~/Downloads/模型.zip` 重建索引。解析 RAR 和 7z 子包时，脚本读取 PATH 中的 `7zz`／`7z`，也可以用 `--seven-zip` 指定可执行文件。macOS 的 `sips` 会转换 TGA、DDS 和 BMP 贴图。模型库保存在 Downloads，GitHub Pages 构建只包含公开运行素材。

模型库未导入时，本机 3D 入口仍可从 `~/Downloads/四糸乃` 读取旧模型。可用 [四糸乃入口](http://127.0.0.1:4173/game/?view=3d&models=yoshino)直接打开，或在局内菜单一次选中 `Yoshino.MDx`、`Yoshino.blp` 和 `YoshinoMagic.blp`。手机通过局域网访问时可使用四糸乃手动导入。

[模型包样例入口](http://127.0.0.1:4173/game/?view=3d&models=sample)使用 `~/Downloads/环界模型样例` 里的引雷柱和黑水玄蛇。部署电弧线圈（T05）可看到引雷柱，第 3 波的铁砂蠕虫（X13）使用黑水玄蛇。其他单位以及缺少样例文件的单位使用低模。样例文件来自 `模型.zip` 中的 `模型/装饰物/lightningrod/` 和 `模型/人物/黑水玄蛇/`，由本机开发服务读取。

- 桌面把鼠标移到战场边缘平移，或用中键拖动。`Shift` 加左键或中键拖动可自由旋转和调俯角，按住 `Insert` 或 `Delete` 可临时左右侧转。滚轮与 `Page Up`／`Page Down` 联动缩放和俯角。
- 手机用单指拖动平移、双指缩放或旋转。建塔时点地图预览，再点确认。战场按钮支持左右转、缩放和全图。「俯角」菜单可以抬高、压低或重置视角。
- 手机和电脑连同一 Wi-Fi，用 `HOST=0.0.0.0 PORT=4175 npm run dev` 启动。手机打开 `http://电脑局域网IP:4175/game/?view=3d&mobile=1`。真机同屏测试在同一地址的 `/game/local-3d/stress.html`，选择模型后运行 120 秒，记录设备、浏览器、分辨率和 P95 帧间隔。

## 操作

- 点击“开始布防”进入对局。部署第一座塔后开始首波 30 秒倒计时。起手 SR 可在卡铺免费领取。
- 底部“卡牌”在卡铺购卡并从卡包部署。选定后面板自动收起。绿色预览表示可放置，红色表示无效并提示原因。道路、中心枢纽、越界及与已有工事重叠的位置不可建造。右键、`Esc` 或3D 指挥区的“取消”退出建造模式。卡片显示价格与用途。
- 底部“装备”可购买散件和查看制作书。
- 退出建造模式后，点击已建造工事打开详情抽屉，查看属性、射程、技能、装备和出售回收值；收起按钮或 Esc 可关闭抽屉并恢复焦点。金币不足或无法操作时会有提示。
- 键盘操作：选择工事后焦点进入战场；用方向键移动虚拟光标，每次 16 像素，按住 `Shift` 每次微调 4 像素；按 `Enter` 部署，退出建造模式后可在光标处选择已有工事。鼠标移动不吸附网格。`Tab` 在按钮间移动，`Enter` 或空格激活按钮。战场中空格暂停 / 恢复，`Esc` 取消选择。
- 底部可暂停或切换倍速。对局菜单可静音或返回主菜单。切到其他浏览器标签页时，战斗按经过的时间继续推进，并遵守手动暂停和倍速设置。浏览器若延迟后台执行，会在下次运行时补算。
- 主菜单和对局菜单的“作战手册”可查看玩法规则、循环圈塔卡与装备。对局中打开手册时战斗照常推进。结算后可重新开始，或在对应难度通关后进入无尽或深渊。

音效在首次用户交互后解锁，使用 Web Audio 现场合成，不需要音频文件。静音会立即停止当前声音及已排队的尾音。浏览器禁用音频时仍可运行游戏。

## 循环圈对局规则

- 开局选择五档难度之一。在卡牌的工人页选择天赋或基础建造。200 初始金币按《环界》的货币尺度折算。N／R／SR／SSR 包价格为 100／120／300／750 金。
- 敌人持续绕圈，积怪达到 60 只即失败。常规 55 波，每五波一名首领。噩梦和地狱采用更高生命倍率并延长波次间隔。开局人口 30，第 11、21、31、41 波扩至 50、70、90、100。N、R 塔占 5 人口，SR、SSR 占 20。
- 战场情报提前两波列出首领机制和反制建议。第 5 至 50 波每隔五波安排打金，第 54 波后再安排一次。打金窗口 20 秒，按实际生命伤害得金币。挑战商店在第 11 至 53 波开放。
- 抽卡、查看塔卡和选择部署位置时，对局继续运行。需要暂歇时可手动暂停。
- 塔依靠击杀经验升级，1／3／5 级解锁技能。主塔建成时分配一种副塔资格。主塔到 20 级，指定副塔升至三阶且在场，即可突破升向 30 级。第 20 波开放五换一的定向 R 卡兑换。
- 基础商店及成装页显示售价和合成材料。神秘商店第 21 波开放，部分货物收木材。未淬武器可以在装备的能量圈页养成。装备主动技能可切换自动和手动，部分技能消耗法力。
- 困难通关可进入无尽，噩梦可选无尽或深渊，地狱进入深渊。无尽继承本局阵容和资源，每十波出现首领。深渊每轮选一座主塔进入中央试炼圈，前三轮为试炼，第 4 轮开始计层。

详细机制见[塔卡与怪物设计](../docs/loop-towers-and-enemies.md)和[装备图标总览](assets/modes/loop/equipment-source/overview.png)。

刷新页面或重新开始会离开本局。主菜单保留本局进度和手动暂停状态，点击“继续布防”回到战场。无账号、存档和排行榜。

## 文件与素材

- `index.html`、`styles.css`：菜单、战场操作面板、帮助与结算。
- `main.js`、`render.js`：交互、资源加载与 Canvas 表现。
- `loop-session.js`、`loop-catalog.js`、`geometry.js`：对局、单位配置和地图几何。
- `audio.js`：本次原创的短音效合成，覆盖发射、命中、击杀、建造、升级、出售、波次、胜利、失败。
- `assets/maps/v6/`：当前战场「镜潮枢庭」的完整原画与运行用 WebP，2D 和 3D 共用同一张地形图。v1–v5 归档了旧地图及其制作素材。
- `assets/original-assets.sha256.json`：开发前原素材内容基线。
- `../outputs/`：只读的原始素材与原清单；游戏直接引用其中的单位方向图与特效。原 `../work/` 源文件与备份也纳入完整性保护，不通过游戏服务公开。

## 检查与验收边界

静态检查可以单独运行：

```sh
node scripts/check.mjs
```

此检查核对原素材全部 808 个文件的清单与 SHA-256、原清单引用、地图 PNG 尺寸与透明叠图、必需 UI ID、游戏及脚本语法。它不运行浏览器，不播放声音，也不证明地图效果和难度平衡已通过。

项目另有 `npm run typecheck` 与 `npm test`。后者通过公开对局接口检查抽卡、部署、装备、战斗和正常经济通关，不操作浏览器或播放声音。最新执行结果见 `qa/verification.md`。

**真实浏览器完整对局、截图、实际试听及地图 / 平衡验收均由用户进行，当前状态为待验收。** 请按 `qa/manual-checklist.md` 记录浏览器、结果与证据。自动化或规则检查通过不能代替上述人工验收。
