# v5 连贯的玉石封印庭院

本轮按用户要求使用 Oil UI 的主次、材质统一、减法和独立视觉复核方法，直接交付已接入游戏的地图，不再发散或请求选方向。

北极星是“科技封印阵嵌进同一片古玉石庭院”：工业黄塔与玄幻单位是前景，浅色铺路清楚，中央玉铜阵盘汇聚四向通道，玉石地块保持平坦。原 v4 的随机管线、分格黑路、独立矩形核心和碎纹章不再叠加。

## 连贯性与可读性

路面、玉石、苔缝和中央阵盘在同一幅原画中完成，沿相同的光照和材质尺度自然衔接，避免分别生成纹理后用另一套图形路面硬切。源场景的色彩与原单位粗描边、玩具体积相协调。

游戏在整张背景上施加一致的轻石玉色，降低纹理对比，不引入局部补丁；敌人接地暗影加强，帮助浅色小单位与浅路分离。移除重复地图标签、中央重叠高亮圈和箭头，保留定位标签和轻呼吸反馈。减少动态效果偏好保持有效。

世界仍是 1280×800，既有外环／内环／十字、中央随机出怪、科技及自由建造规则不变。建造浮层仍不挤动主区域，原 808 文件与 v1–v4 图片和制作源文件全部保留。

## 验证边界

在原画实际 RGB 颜色上检查非节点路段附近的浅色铺路，并对 668 处合法建造占地的角／边／中心邻域做路面色彩筛查。这是与本图色板有关的近似校验，不是语义分割或像素级准确性证明；节点装饰、中央核心和整体衔接另由红线叠图与独立看图复核。

类型、语法、资源和原素材完整性检查由实现者执行。页面真实操作、不同视口和音效仍按既有约定由用户验收，不使用资源图假称已完成浏览器实测。
