# 对局界面减法（2026-11-04）

用户确认采用“顶部战况、底部主操作、低频操作收入菜单”的方向。科技与玄幻的现有材质保留，界面降低边框和颜色数量，战场仍是视觉主体。本次不修改地图、美术源文件或战斗数值。

- 顶部只保留模式、金币、波次与容怪／核心状态；下波详细信息、击杀和补充敌人统计移入菜单，波次标签仍保留自动备战／下波倒计时。
- 底部突出建造、科技；暂停、倍速、菜单降为辅助操作。桌面为居中操作条，手机贴底并兼容安全区。
- 菜单承载任务／循环圈情报、声音、返回主菜单和手机视野控制。返回主菜单仍需确认，取消后保留对局。
- 原有选塔详情按选中时出现。保留建造与科技浮层的固定定位，不挤压地图。
- 科技入口展示研究百分比及按钮内进度，详细研究操作仍在面板。开局提示从5秒缩为3秒并同步新入口名称；补给的常规金币变化不再反复弹出通知。
- 复用已有面板滑入与按钮按下反馈，补充短提示淡入；减少动态效果时跳过动画。

## 验证

定向 UI 测试16项通过，包含新增菜单面板切换、研究入口进度回归；项目类型、语法、DOM ID和原素材哈希检查通过。未进行全量试玩和真实手机验收。

独立 headless Chrome 检查320×568、390×844、844×390、1440×900：从真实菜单进入，验证建造／科技开关前后canvas边界完全一致、研究进度、菜单情报、声音开关、取消退出、暂停和倍速，无横向溢出或脚本异常。交互脚本连续三轮通过；截图等待面板动画结束。过程证据在 `.scratch/2d-loop-td/quiet-hud/`，包括修改前后及菜单截图，不进入部署产物。

视觉自查一轮：修正手机主按钮不等宽、面板截图截到动画中途的问题；没有增加与玩法无关的装饰动效。独立 UX 走查由 `/root/quiet_hud_ux` 完成，路径为首页→循环圈→建造→选择炮塔→落地→等待首波并观察攻击。走查发现倒计时入口过深、手机取消提示不合适，两项均已修正：顶部原波次标签显示倒计时，底部建造在待放置时切换成取消放置。主 Agent 另用原生触摸事件验证一键取消不扣款、触摸预览确认只建一座。走查提及手机地图留白属于主游戏区域，本轮按用户约定保留。桌面菜单随后改为按内容高度展示，避免空面板遮挡。独立截图以 `ux-` 开头；修正后由主 Agent 验证，不宣称做过第二轮独立走查。
