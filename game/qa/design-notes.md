# 视觉与操作说明

设计方向：以环路战场为视觉主角，原有科技单位的工业黄与玄幻单位的玉青作为辨识色，深玉绿控制区包围明亮的玉石苔庭地图。方向沿用已确认的原素材规范，没有另开不相关的美术候选。

玩家主要任务是选择塔位、安排输出与控制、升级经营。界面保留金币、波次、积怪与上限四项核心信息，辅助说明退到选择面板与玩法弹窗中。

地图交付独立背景、道路和底座位图，角色、血条、塔位选择及射程由运行时叠加。原图固定锚点和统一缩放，绘制时不依照每一张方向图的外框重新裁切铺满。

交互反馈覆盖按钮按压、塔卡选中、菜单初次入场，以及建造扩散圈、升级、命中和金币浮字。减少动态效果偏好会关掉界面出场动画和单位轻微起伏，游戏规则继续运行。

目标设备为电脑横屏；窄窗口侧栏堆叠。键盘可聚焦按钮及画布，画布方向键选择塔位，按 Enter 执行已选工事部署，空格控制暂停，Esc 取消选择。

真实浏览器完整流程、音效和 200% 缩放检查由用户在全量验收时执行。静态图片查看和代码审查不能替代这部分，尚未完成的视觉与体验验收见人工清单。
