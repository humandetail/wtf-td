# 视觉与操作说明

当前地图采用参考布局 v3：外环、内环和中心横纵通道互相连接，中心保留枢纽。道路组成清楚的几何骨架，工事区域使用平坦地块，避免层叠山石和装饰侵占可建造空间。原有科技单位的工业黄与玄幻单位的玉青继续用于单位辨识。

玩家先选工事，再在绿色有效区域连续坐标放置，没有预设建造点或 20 座位置限制；空间、占地和金币决定能否继续建造。地图背景与道路作为素材层，单位、半透明建造预览、有效区域、十字光标、选中标识和射程由运行时叠加。鼠标不吸附网格，单位绘制沿用固定锚点与统一缩放，不按各方向图外框重新裁切铺满。

建造判断覆盖完整占地，不能侵入道路、连接通道、中心枢纽或地图边界，也不能与现有工事占地及必要间距重叠。有效预览为绿色，无效为红色并说明原因；金币不足同样拒绝，重复拒绝不扣费。成功后保持工事卡选中以便连续建造，右键、Esc 或取消按钮退出。退出后点击已有工事查看属性、升级或出售，工事通过稳定唯一 ID 识别，出售释放占地，原处重建不会混淆选择。

界面保留金币、波次、积怪与上限四项核心信息，建造状态显示当前工事及有效性。金币、相邻辅助工事或操作状态变化后刷新预览和选中属性。重开清除上一局选择、预览与建造模式。界面继续使用原生 HTML 控件与 Canvas，不引入框架。

目标设备为电脑横屏，窄窗口侧栏堆叠。按钮与画布可用键盘聚焦；方向键移动可见十字光标，每次 16 像素，Shift + 方向键微调 4 像素，Enter 在建造模式中部署、退出后选择光标处工事。鼠标移出隐藏鼠标预览，下一次键盘操作恢复键盘光标。空格暂停或恢复，Esc 取消建造与选择。

交互反馈包括按钮按压、工事卡选中、菜单入场，以及建造、升级、命中与金币变化效果。减少动态效果偏好关闭界面入场动画和单位轻微起伏，游戏规则继续运行。

资源和场景可通过原生场景查看器的复选框切换图层，检查道路、地块及单位素材；这种资源场景查看不等同于浏览器对局验收。真实浏览器完整流程、半透明预览表现、实际试听、地图主观接受度及 200% 缩放检查均由用户进行，当前仍待验收。人工清单中的原生 Markdown 复选框仅记录用户实际结果，未勾选项不代表通过。
