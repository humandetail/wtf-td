# 视觉与操作说明

设计方向是“科技封印阵嵌进一整片古玉石庭院”。原科技塔工业黄与玄幻单位作为前景，浅色铺路、玉石地块和铜玉核心在一张完整场景里统一材质、光照和磨损尺度；地图沿用外环、内环、中心四向出生与连续坐标建造，不改战斗或科技规则。

默认战场由紧凑顶部 HUD 和弹性地图区构成。底部建造带作为战场内部的绝对定位浮层，默认收起，点击顶部“建造”展开；开合均不占布局空间、不改变地图尺寸或位置，切换按钮固定宽度避免顶栏重排。选塔后自动收起并聚焦地图，当前种类可连续建造。重新开始恢复默认大地图；继续对局保留所选布局。建造带横向滚动，完整塔名、费用和锁定原因保持可读。

“科技”打开按需右侧抽屉，点击已有塔打开详情抽屉；抽屉不占常驻地图宽度，关闭按钮或 Esc 可收起并恢复入口／画布焦点。打开科技或详情会收起建造带。HUD 始终保留建造与科技入口，避免收起后无法恢复。

ResizeObserver 以地图容器真实剩余空间设置 canvas CSS 宽高，始终 8:5。画布输入边界与绘制内容一致，指针仍通过实际边界转换到 1280×800 世界；不以 object-fit 拉伸或在输入框内部留黑边。窄、短窗口的控件使用有边界的滚动区域，不缩成不可读小字。

地图资源是 v5 完整场景，所有路径在原画内自然相连，不再用独立黑蓝方板覆盖。中央核心嵌入铺地，不阻挡出怪；建造区为安静、平坦的玉石，移除断头管线和孤立纹章。统一压低背景对比、加强敌人接地暗影，不改原素材与旧图。

科技按已确认表控制塔容量、种类和升塔前置。建造预览与实际建造共享检查，绿色有效、红色无效并说明原因；金币、科技或容量变化后更新。出售释放占地与容量，建筑身份不随位置重用。

沿用按钮按压、选中反馈、菜单入场和战斗粒子；抽屉短促入场，减少动态效果时直接显示状态，模拟继续运行。键盘移动光标、Shift 微调、Enter 建造／选择、空格暂停保持不变。

已查看 v5 整体原图、路线叠图及原单位场景合成；资源与类型检查可以核验对齐、占地和结构。未操作浏览器或桌面，不能将这些合成图、代码检查或尺寸计算称为实际界面截图、布局改善百分比或真实交互通过。真实视口、200% 缩放、抽屉与滚动手感、声音和主观地图验收继续由用户执行。
