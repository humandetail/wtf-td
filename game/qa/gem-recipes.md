# 默认资源配方取得与实战记录

2026-10-31。本记录补充原20个未筛选种子的普通合成基线，不能替代随机性／整体难度验证。五个配方各进行一局独立默认400金币对局，统一使用固定示例种子42；没有为每个配方筛选有利种子，也没有写入材料、科技、金币、血量或敌人数值。全部操作通过会话公开命令完成。

## 复现

```sh
node --test game/tests/gem.test.mjs
node game/qa/gem-strategy.mjs --recipes > game/qa/gem-recipe-runs.json
```

不带`--recipes`仍运行原来的20种子基线（1、42、2026、2至18），不改变该基线的选择、合成或研究策略。带`--recipes`生成五局的候选／刷新、选留、合成、研究、融合和战斗记录。[实际输出](gem-recipe-runs.json)保留逐命令参数、金币前后值、候选及选留结果、真实融合输入、每波阵容与科技、各单位发射次数和回响事件。

## 策略

目标配方所需二阶材料优先选留；一阶同系材料通过真实普通合成取得二阶，已经齐备的二阶材料不自动合成掉。先付费研究强化至二级，再完成部署及后续科技。每局付一次开局20金币刷新；目标未取得时，候选缺乏有效目标材料且支付后仍有120金币余量，才额外刷新。阵位沿地图两条平行路径的共享火力走廊选择合法位置，不使用固定敌人注入。

F05先取得并部署F01和F03，两者至少各经历一波真实战斗，完成部署3／强化4后才融合；融合后继续保留其他攻击宝石触发回响。取得最终目标后停止为该配方刷新或重建已消耗的前置配方，余下资源照常经营防线。

## 自动检查与取帧接口

新增回归逐局检查默认400开局、六类真实指令（鉴定／付费刷新／选留／普通合成／研究／配方融合）、全部五结果的真实攻击或回响、F05前置配方先实战，并将完整成功命令账本在另一份全新400金币会话中逐条重放。每次重放核对金币及候选，最终胜负、耐久、金币和击杀数必须一致，重放过程不写入会话状态。

`playGem(seed, {recipeTarget:'F05', onFrame(state, events) { … }})`在每次真实`tick(.5)`后调用回调。`events`为该次tick后刚从会话排出的完整真实事件，包含此前准备阶段的融合／建造事件；回调在下一tick前同步执行，可直接用于原生Canvas渲染与特效采样。`state`是实时会话状态，若要跨帧保存应自行复制，回调不得修改规则状态。未提供回调不改变策略行为。

实际浏览器、动画主观接受、试听和难度体验仍未执行，由用户按人工清单验收。
