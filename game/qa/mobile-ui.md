# 图标指挥栏与手机网页版

2026-11-02。沿用现有青铜／玉色界面与全部七模式规则，原素材不改动；没有另建一份玩法代码，也没有增加生产依赖。

## 使用

桌面刷新原游戏页面即可看到建造／科技／任务等SVG图标加短标签，暂停和静音图标随状态变化。窄屏或手机自动使用触屏布局；`/game/?mobile=1`可以强制开启手机界面。

本次单独启动手机服务4174，手机与电脑连接同一Wi-Fi后访问 `http://10.10.2.73:4174/game/?mobile=1`。这是当前电脑局域网地址；重启服务可用：

```sh
HOST=0.0.0.0 PORT=4174 npm run dev
```

电脑网络地址变化后，使用新的局域网IP。默认不设置HOST时仍仅监听127.0.0.1；静态服务继续只开放game／outputs，.git和work仍404。

## 操作

- 底部图标栏固定，顶部收紧到金币／波次／积怪或耐久。科技和建造作为底部浮层展开，不改变地图尺寸；正文／控件可滚动。
- 视野工具切换1／1.5／2倍，放大后可拖图，按“返回点选”恢复操作，按“全图”复位。指令坐标按经过变换的canvas矩形换算。
- 手机建塔、宝石部署、搬迁及技能指向：点位置先预览，再点确认执行。拖动、多指、取消或暂停不会因合成click重复购买。
- 英雄左下摇杆控制移动；松手、取消、失焦、暂停、面板及菜单清零移动。未武装时点地移动、点怪指定目标、点塔查看；Q/E/R点技能后选目标确认。
- iPhone安全区、横竖屏、320px七键底栏均有布局规则；44px主要触摸目标。横屏视野更开阔，竖屏可放大拖动。
- 图标沿用统一线性笔画，保留文字与状态；按压反馈、底部面板滑入淡入、摇杆跟手，减少动态效果设置沿用原全局规则。只收起手机次要常驻统计，不删除规则说明。
