- [ ] 菜单中单位原图清晰、构图完整；玩法说明可打开、关闭，`Esc` 可关闭弹窗，关闭后焦点回到入口。

## 自由建造与经营

- [ ] 先选右侧工事，再在绿色有效区域任意放置；未选工事时点击空地只提示先选工事，不扣费、不建造。
- [ ] 鼠标连续移动时，半透明单位预览随精确坐标移动，不吸附网格、不跳到预设位置；可在同一区域选择不同的非整数坐标放置。
- [ ] 有效位置显示绿色预览；无效位置显示红色预览，并在建造状态中明确说明道路、中心枢纽、越界、占地重叠或金币不足等原因。
- [ ] 在外环、内环、横纵连接道路、中心枢纽及地图边缘分别尝试放置；判定覆盖完整工事占地，中心点在空地但占地侵入道路、枢纽或边界时仍被拒绝。
- [ ] 在已有工事中心、边缘和间距不足的位置尝试放置均被拒绝；留出足够空间后可建造，预览与实际结果一致。
- [ ] 金币不足、重叠、道路、枢纽和越界的重复点击均不扣费、不新增工事；建造模式中点击已有工事只显示拒绝原因，不改选另一工事。
- [ ] 成功后仅扣显示价格，选中新建工事；当前工事卡保持选中，移到另一有效位置可以连续建造。
- [ ] 开局最多 4 座，部署科技依次开放 8／12／20 座；满额后预览和实际建造均明确拒绝，出售一座后立即恢复一个名额，仍可选择任意合法位置。
- [ ] 右键不打开画布浏览器菜单，且退出建造模式；`Esc` 和“取消建造”同样退出并清除预览。再次选工事能恢复建造。
- [ ] 鼠标移出画布隐藏预览；再次按方向键或 `Enter` 恢复键盘操作。鼠标与键盘切换后，预览和十字光标对应当前输入方式，无残留幻影。
- [ ] 金币因建造、击杀、补给、升级或出售改变后，预览有效性和失败原因及时更新；暂停 / 恢复后与实际建造结果一致。
- [ ] 重新开始后没有旧预览、旧选择或旧建造模式，键盘光标恢复初始位置；随后选择工事可正常操作。
- [ ] 退出建造模式后点击已有工事能看到名称、作用、属性与射程；选中标识可辨认，`Esc` 能取消。
- [ ] 升级扣除显示费用，等级、属性、升级价格同步变化；金币不足时按钮显示所需金币，达到 5 级后不能继续升级。
- [ ] 出售回收累计投入的 70%（向下取整），占地立即释放，可原处重建；出售前后多次选择、升级不同工事时，操作始终作用于实际选中单位，稳定唯一 ID 不因数组顺序或原处重建而混淆。
- [ ] 开局仅有自动拦截炮、微波干扰和水炮，其余塔随部署科技逐级开放；最终 12 种工事均可建造，输出、控制、辅助用途可观察；雷达、维修臂与补给站能产生对应效果，附近辅助工事变化后，选中单位属性同步刷新。

## 科技研究

- [ ] 两项科技开局均为 0 级，部署容量 4、塔等级上限 1；未解锁卡片保留可见并显示所需科技等级。
- [ ] 部署 1／2／3 级分别解锁 8／12／20 座及 6／9／12 类塔，所有输出与辅助塔计数；右侧容量与可建类型同步更新。
- [ ] 强化 1–4 级只开放塔 2–5 级升级资格，已有塔不自动升级，仍需逐座支付升级费用；缺少科技时按钮说明原因。
- [ ] 研究开始扣除显示费用，倒计时可见，全局仅一项且不预排队；进行中不得按目标科技提前建造或升塔。
- [ ] 取消未完成研究全额退还本次费用，清空进度，已完成等级不变；重复取消不重复退款。
- [ ] 暂停／返回菜单时研究停止，倍速按游戏时间加速；研究完成提示、商店卡片、已选塔升级和放置预览及时刷新。
- [ ] 通关时未完成研究冻结，选择无尽后从剩余时间继续；失败停止，重开两项科技与任务清零。
- [ ] 科技区、容量、取消按钮在常用桌面与较窄窗口仍可操作，商店可滚动且键盘聚焦不会被遮挡。

## 对局与规则

- [ ] 普通怪和 Boss 从中央出生，每只独立随机向上／右／下／左出发，入口标识位于中心且不再指向左上角。
- [ ] 单位自动攻击有效射程内敌人；发射、命中、血量变化与死亡表现一致，击杀奖励只结算一次。
- [ ] 观察一名未击杀敌人绕完整圈：它继续行进，不自动消失，也不扣除另一套基地生命。
- [ ] 留有旧敌人时，新波次仍按倒计时加入；存活数量与画面一致，积怪压力清楚可见。
- [ ] 暂停后移动、出怪、倒计时、攻击与经济停止推进，恢复后继续；倍速确实改变推进速度。
- [ ] 切换浏览器标签页会自动暂停，返回后不会突然推进大量时间，可手动恢复。
- [ ] 第 5、10、15、20 波均有可识别首领；首领尺寸、血条与战斗表现清楚。
- [ ] 完成常规 20 波且清除全部残敌后才出现胜利结算，尚有残敌时不会提前胜利。
- [ ] 不建塔或主动制造积怪，实际存活怪物达到 80 时立即失败，结束后对局停止推进。
- [ ] 失败结算清楚解释容怪上限原因；胜利 / 失败战报与本局实际结果一致。
- [ ] 重新开始清除上一局塔、敌人、金币变化、暂停与倍速状态，恢复初始对局。
- [ ] 胜利后进入无尽模式，保留塔与金币，后续波次正常推进且仍有失败条件。
- [ ] 返回菜单、刷新页面与重新开始的行为可理解；本版没有对局存档。

## 实际音效

请使用可听音量验收，不要只检查事件或音频节点。

- [ ] 首次用户交互后声音可播放，菜单加载不强制自动播放。
- [ ] 发射、命中、击杀、建造、升级、出售、波次、胜利、失败都有相应且可辨的短音效。
- [ ] 密集战斗声音不过度刺耳或失控叠加，音量与节奏适合连续游玩。
- [ ] 点击静音后正在播放的声音与已排队尾音立即停止；保持静音时新事件不发声。
- [ ] 恢复声音后新事件正常发声，不补播静音期间积攒的事件。
- [ ] 在目标浏览器（如 Safari）确认音频正常；浏览器不支持或禁用音频时游戏仍可操作。
