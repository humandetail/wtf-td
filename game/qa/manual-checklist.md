# 循环圈试玩清单

记录浏览器、设备、渲染分辨率、随机种子和实际结果。

- [ ] 从首页选择难度，在工人页选择天赋并建基础塔。确认第一座塔部署后启动 30 秒备战，卡铺可领取免费起手 SR。
- [ ] 部署、出售、抽卡、人口扣还及装备购买、合成、装配能正常操作。道路、中心枢纽和已有塔占地不可部署。
- [ ] 2D 和 3D 在相同种子与操作下核对金币、积怪、击杀、首领打断、结算和无尽。切换视图后本局继续。
- [ ] 验证第 20 波兑换、第 21 波神秘商店和第 54 波最后一次打金。用符合条件的难度通关，从战报进入无尽或深渊。
- [ ] 深渊每关只派一座主塔。验证试炼圈中的走位、超时使用一次机会、返回选塔后恢复原位置。
- [ ] 检查镜头在多种朝向、俯角与缩放下的部署和装备选点。键盘、鼠标和触控分别试一次。
- [ ] 手机上先预览再确认，拖动、双指手势、取消或切换视图不会误部署。检查小屏上能滚动详情，指挥区可操作。
- [ ] 手动暂停和加速有效。未暂停时切到其他标签页，回来后确认波次和计时已经推进。暂停后重复切换，确认计时停住。查看手册或往返主菜单时保留暂停状态。静音后停止播放。
- [ ] 用 iPhone Safari 和 Android Chrome 运行本地 3D 满场测试 120 秒，记录 P95 帧间隔，并与 33.3 ms 目标核对。
