## 入口与可操作性

- [ ] 首次加载能看到资源加载进度，完成后显示菜单，没有资源报错或控制台异常。
- [ ] 菜单中单位原图清晰、构图完整；玩法说明可打开、关闭，`Esc` 可关闭弹窗，关闭后焦点回到入口。
- [ ] 开始对局显示 400 金币、80 容怪上限和首波准备倒计时，地图与侧栏可操作。
- [ ] 按钮可用键盘聚焦并有明显焦点样式；聚焦战场后方向键与 `Enter` 可以选择塔位。
- [ ] 在常用桌面横屏、较窄窗口与 200% 缩放下，没有按钮或关键文字重叠、裁切，窄屏侧栏能正常堆叠。

## 建造与经营

- [ ] “先选塔位再选工事”和“先选工事再选空塔位”两条路径都能建造，金币正确扣除、单位落在底座上。
- [ ] 金币不足、塔位已占用时不能重复扣费，并有明确反馈。
- [ ] 选中已有单位能看到名称、作用、属性与射程；选中标识可辨认，`Esc` 能取消。
- [ ] 升级扣除显示费用，等级、属性、升级价格同步变化；达到 5 级后不能继续升级。
- [ ] 出售回收累计投入的 70%（向下取整），塔位被释放，可重新建造。
- [ ] 12 种工事均可建造，输出、控制、辅助用途可观察；雷达、维修臂与补给站能产生对应效果。

## 对局与规则

- [ ] 单位自动攻击有效射程内敌人；发射、命中、血量变化与死亡表现一致，击杀奖励只结算一次。
- [ ] 观察一名未击杀敌人绕完整圈：它继续行进，不自动消失，也不扣除另一套基地生命。
- [ ] 留有旧敌人时，新波次仍按倒计时加入；存活数量与画面一致，积怪压力清楚可见。
- [ ] 暂停后移动、出怪、倒计时、攻击与经济停止推进，恢复后继续；倍速确实改变推进速度。
- [ ] 切换浏览器标签页会自动暂停，返回后不会突然推进大量时间，可手动恢复。
- [ ] 第 5、10、15、20 波均有可识别首领；首领尺寸、血条与战斗表现清楚。
- [ ] 完成常规 20 波且清除全部残敌后才出现胜利结算，尚有残敌时不会提前胜利。
- [ ] 不建塔或主动制造积怪，实际存活怪物达到 80 时立即失败，结束后对局停止推进。
- [ ] 失败结算清楚解释容怪上限原因；胜利 / 失败战报与本局实际结果一致。
- [ ] 重新开始清除上一局塔、敌人、金币变化、暂停与倍速状态，恢复初始对局。
- [ ] 胜利后进入无尽模式，保留塔与金币，后续波次正常推进且仍有失败条件。
- [ ] 返回菜单、刷新页面与重新开始的行为可理解；本版没有对局存档。

- [ ] 在目标浏览器（如 Safari）确认音频正常；浏览器不支持或禁用音频时游戏仍可操作。
