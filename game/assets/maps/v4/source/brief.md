# v4 科技与玄幻冲撞地图

2026-10-31，用户要求扩大主战场占比，并让地图呈现科技与玄幻冲撞的风格。

视觉主线：工业黄科技塔驻守被机械导轨侵入的玄幻遗迹；冷青线路与玉石／符紫灵脉在地面相互侵入，中央为机械锁环约束的出怪法阵。使用原单位的玩具体积感、描边和左上光照，不改原素材。

世界仍是 1280×800，外环／内环／十字路网、48px道路、中央出生与自由建造规则不变。所有可建区域必须呈现平坦地表，地面只使用嵌平金属板、石片、低苔和细纹，不绘制阻路的高物体、固定塔位或假建造底座。边界允许少量裁切的机械／古岩装饰。

新版地面、道路、提示词及源图独立存入 v4；v1–v3 与 outputs/work 均保留。地面由内置 imagegen 制作，几何道路继续沿用现有可编辑 SVG 资产体系。

布局主线：顶部紧凑状态栏，地图占据剩余弹性空间，底部窄建造带；科技与选中详情按需打开抽屉，专注模式进一步释放空间。以 canvas 实际显示尺寸映射点击，始终保持 8:5。

验收：图层资源合成查看、原素材摘要、道路像素及类型／公开规则检查。用户已保留真实试玩，继续不运行浏览器或桌面取证；不会将资源合成称为页面截图。
