# 地图连贯性修正 · Oil UI 设计方向

用户要求直接交付成品，不再提问。本轮延续科技与东方玄幻的已定方向，修正同一张地图中的材质、尺度和空间连贯性，不再发散成候选风格。

北极星：科技阵列嵌进一整片古玉石遗迹，人物和塔最醒目，真实路网清楚，中央核心汇聚，建造地块安静。

当前问题：v4 地面中的随机管线和大纹章被另一套深色方板路面切断，地表碎叶、道路分格和单位大色块不在同一细节尺度；中央矩形面板像独立贴片。

成品决定：

- 地表重新绘制为一整片低对比、大尺度、平坦玉石庭院，苔藓收在边缘和石缝，移除地块里的断头管线、孤立圆章和紫色分区。
- 第一轮验证了同源地面采样，但路线辨识不足；最终按相同几何把路面、地块与核心整体绘成一张场景，采用浅矿石铺路／玉石地块／铜色封印的一套材料，不再覆盖独立黑蓝方板。
- 科技线路只沿真实路网延伸并连至中央核心，不在可建地块里暗示另一套路网。道路交叉处是同一块铺地，不重复叠加横竖分格。
- 中央采用嵌地的玉铜阵盘连接四向道路，去掉矩形底板与多套重叠的高亮符号。
- 沿用原单位的玩具 2.5D 体积、粗描边、暖左上光照；新背景保持低频细节和克制色彩。
- 既有世界、道路、中央随机出生、科技与自由建造、建造浮层不挤动主区域的规则保持。

证据边界：查看原图、成品地图及与原单位合成后的资源场景；独立视觉审查看实际图像。真实浏览器交互仍按用户此前约定保留，不把资源合成称为页面截图。

素材独立存为 v5，原 808 素材与 v1–v4 资源完整保留。最终场景由内置 imagegen 整体另存，权威几何叠线用于核对真实路网；第一轮地面、同材质 SVG 原型及生成脚本也保留为过程资料，不进入运行时。


独立视觉审查后的精修：整张静态背景统一叠加 12.2% 的石玉色，压低地面纹理对比，不对地块增加局部色块；敌人接地暗影加强至 40%，普通暗影横半径为 19，帮助红白小型敌人与浅色路面分离。原单位图和场景原画不改，资源预览使用同样的场景渲染参数。

删减：取消外环／内环的悬浮装饰标签及重复的“四向随机出怪”说明，保留有实际定位意义的“出怪核心”；移除中央多套高亮圈与箭头，仅留克制的呼吸效果，避免与画内阵盘争夺注意。
