# 拦剑双响 / tech-interceptor-01

## 选型

选择 concepts.png 中间候选。左候选轮廓较圆，右候选支架与炮轴更复杂；中间的宽体箱形、双管、侧箱组合小尺寸更易读，中央转盘也适于分层。master.png 是所有方向共用视觉基准。

## 不变造型

- 工业黄参考 #EDB735，冷灰 #47525C，米白 #EAE3CE，轮廓 #202A33，少量青蓝 #56DAED。生成图允许色阶变化。
- 固定底座：低矮宽八边形；米白平整上甲板，前中央黄色面板和深色散热口，前左冷灰面板有单个青蓝灯。底座正面在屏幕下方，前边水平。
- 上层：圆角宽箱壳体，黄色侧肩，深灰顶部桥板，米白 U 形前框。
- 恰好两根平行、等长、等径的短粗灰炮管，每管近炮口一个黄环；间距约一个管径；水平安装，不做俯仰动画。
- 上层自身右侧只有一个黄灰弹药箱，深色中带和锁扣。定义前为炮口发射方向，后为壳体散热端；自身右侧是面朝前时的右手侧。因此 S 时侧箱在屏幕左，N 时在屏幕右；E 时近侧，W 时远侧。
- 搜索雷达在后上方中央短桅杆上，黄边水平矩形面板；正面灰板与青蓝灯朝向炮口，背面灰色凹板无青蓝灯；不加天线。
- 后侧补全：圆角黄色后盖，一个居中的深灰矩形散热口，下方小检修盖。后部无额外弹箱或炮口。
- 双管、壳体、右弹箱、雷达及黑色转盘为一个刚性旋转组件；固定中央竖直轴。
- 分层边界：黑色转盘下缘与米白底座上甲板接触面；整块黑转盘属于上层。底座无高于甲板的前围栏，允许单底层 + 单上层合成。

## 坐标

画布 512×512。地面轴锚点 (256,320)，上层转盘中心约 (256,265)。底座固定；所有上层依据同一转盘直径与中心注册，不按完整外框自动铺满。E=0°，SE=45°，S=90°，SW=135°，W=180°，NW=225°，N=270°，NE=315°。屏幕 X 向右，Y 向下，角度顺时针增加。

画面投影：N 炮管向上、可见背部；S 炮管向下、可见炮口。E/W 侧面双管会自然互相遮挡，不将远侧炮管移位来展示。
