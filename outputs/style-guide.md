# 美术规范

单元：现实科技阵营「拦剑双响」自动拦截炮塔、微波干扰塔、重型榴弹炮塔，以及东方玄幻阵营的御剑纸符小妖、青铜石狮、葫芦法师。东方玄幻单位在本轮作为待机敌方素材，不生成战斗场景或攻击特效。

- 2.5D 潮玩卡通，桌面工程玩具体量；短粗、大形体、圆润倒角。
- 深炭色粗外轮廓，较细内部线；轻微手绘变化，不使用草稿抖线。
- 哑光塑料和涂装金属，大色块，2–3 档赛璐璐明暗，柔和局部高光；不使用写实纹理、锈蚀或强镜面。
- 科技配色：工业黄、冷灰、米白；少量蓝色指示灯。保持现实机械连接与中央旋转机构。
- 共享敌方语言（后续）：朱砂红、玉青、暖金、墨紫；飞剑、符箓、葫芦、铜铃、八卦镜、石狮、狐妖；以云纹、玉石、青铜、木材和布料体现玄幻。共享同一描边、比例、光照和渲染精度。
- 正交相机，相对水平面向下约 30°；相机和缩放固定。物体上层绕竖直轴旋转，底座不动。
- 主光固定在画面左上；允许轻微结构 AO。透明素材不带地面投影，预览单独添加统一阴影。
- 主检查尺寸 96×96，另检查 64、128、256。炮管、轮廓、弹药箱优先于细碎装饰。
- 最终资产画布 512×512，旋转轴地面投影锚点 (256,320)，左上 (0,0)。不可用各自包围盒自动铺满。
- 真 Alpha PNG；八方向属于离散转向，不是连续三维旋转。
