# 二维游戏保留现有素材的立体外观

用户要基于现有素材制作二维循环圈塔防，并在选项确认中采纳了“保留现有外观、使用八方向图片”的推荐。采用平面移动与战斗规则，继续使用现有带透视和体积感的透明单位图片，而不将“2D”解释为重新绘制全部单位；这样保留已投入的美术成果，也避免为纯平面外观重做整套方向图。

后续地图应匹配这套单位的视角、比例和光照。方向图是离散视图，并不等同于连续三维模型，因此转向表现需要适配现有素材能力。

此记录确认美术复用方向，不代表已授权游戏开发或地图制作。素材保护边界、地图交付与开工确认状态以[正式规格](../../.scratch/2d-loop-td/spec.md)为准；[需求确认稿](../2d-loop-td-brief.md)保留访谈记录。
