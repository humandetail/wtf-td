# 循环圈以低容量和互斥专精形成阵容取舍

2026-11-03，针对“塔种已有很多但策略不足”，决定先只改循环圈，保留14塔素材并重新划分近战／远程／辅助职责，用敌人的重甲、护盾、速度和治疗制造不同阵容需求；不把其他六种模式强行统一。塔保持五级，三级二选一专精、五级标志技能，科技高阶增强已选能力而不同时获得两条路线，避免塔升满后通吃所有职责。

部署科技0—5级的容量最终确定为4／6／8／10／12／16，否决此前最高32座建议；辅助和经济塔同样占一个名额，使铺塔、养塔、辅助及经济之间具有机会成本。近战采用路旁短距离攻击，不引入拦路、承伤与守卫生命管理；技能以自动／条件触发为主，保留手机操作可用性。完整规则见 [规格](../tower-strategy-spec.md)，初稿数值见 [数值表](../tower-strategy-balance.md)；方向已确认，不代表首版平衡已验证或代码已实现。
