# Issue tracker: Local Markdown

用户已选择本地 Markdown tracker。每个功能的规格位于 `.scratch/<feature>/spec.md`，任务票位于该功能的 `issues/`，每票一个按依赖顺序编号的文件。

任务票的 Blocked by 记录真实前置任务。状态使用 ready-for-agent、in-progress、done；需要用户实际体验的验收票使用 ready-for-human。只有全部前置条件满足才能将业务流程标记完成；独立的素材或界面准备工作可以先行。

当前功能为 2d-loop-td。用户在 2026-10-30 明确授权开始实现及并行子 Agent；全量真实测试留待全部开发任务完成后再次询问。标签本身不替代最新用户指令。
