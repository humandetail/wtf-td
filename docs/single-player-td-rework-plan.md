# 环界单人塔防改造计划

## 目标与范围

在现有《环界》里交付一套完整的单人循环圈对局。玩法以用户提供的《刀圈TD》正式版 6.25 第七赛季的个人模式为准，涵盖开局、55 波主线、塔与装备成长、经济活动、无尽和深渊。使用《环界》的地图、原创塔与敌人、名称和美术编排。桌面和手机继续使用同一套战斗规则，本地 3D 复用现有模型库。

当前实现已有 50 波、36 张塔卡、58 种敌人、30 件装备，以及抽卡、突破、打金、主动挑战和无尽。部分后期波次复用模板，人口从 100 起步，定向兑换第 15 波开放。实施以当前代码和已通过的 63 项测试为基线。 [对局契约](../game/CONTRACT.md) · [塔与波次配置](../game/loop-roster.js) · [装备配置](../game/loop-equipment.js)

## 玩法范围

| 系统 | 单人版规则与实施范围 |
| --- | --- |
| 开局与卡池 | 加入工人天赋、起手英雄和可直接建造的基础塔，接入 N／R／SR／SSR 卡池。核对各档抽取费用、概率、回收及定向兑换规则。部署成功后扣除卡牌或资源，出售按个人模式结算。 |
| 人口与塔成长 | 第 11、21、31、41 波的人口上限依次为 50、70、90、100。逐塔配置攻击、射程、属性成长、技能等级与解锁条件。主塔建成时抽取 13 种资格之一，20 级时检查对应满阶副塔，解锁后续成长及高阶装备。第 20 波开放 R 卡定向兑换。 |
| 主线与容怪 | 单独配置第 1–55 波的敌群、数量、出生间隔、刷怪窗口、生命、移动、奖励和特殊能力。敌人沿环路持续移动，前后波可同时在场，容怪达线时结算失败。每 5 波进入首领轮，第 55 波使用独立终局倒计时。补齐次数盾、隐匿、闪避、高魔抗、召唤、净化和可打断施法等对策。 |
| 打金与挑战 | 第 5 至 50 波每隔 5 波安排一次打金，第 54 波后再安排一次。参考倒计时 10 秒及打金窗口 20 秒，单独结算金币怪伤害与收益。第 11 波开放挑战商店，第 54 波清理挑战入口和对应目标。逐项配置挑战费用、计时、奖励和超时处理。 |
| 装备与商店 | 接入常驻散件、制作书、成品、挑战奖励和神秘商店。神秘商店第 21 波开启，第 26、31、36、41、46、51、52、53、54 波刷新，最后一次刷新后 120 秒关闭。补齐购买、合成、穿卸、出售、主动施放、冷却及装备资格。恢复破损妖刀在能量圈养成和每主塔限带一把的规则。 |
| 难度与终局 | 保留简单、普通、困难、噩梦、地狱五档，参考主线基础生命倍率 0.8、1.2、1.62、2.5、2.6。终局倒计时参考 480 秒，按个人模式核对击杀和失败条件。困难开放无尽，噩梦可选无尽或深渊，地狱开放深渊。 |
| 无尽 | 继承主线塔、装备、资源与突破状态。普通波从 4 类敌人中抽取，每 2 秒投放一批，刷怪窗口 14 秒。每 10 波从 7 类首领中抽取一类并立即投放一批。依据个人模式配置生命成长、容怪和奖励，独立记录最高波。 |
| 深渊 | 每关选择一座主塔出战，采用深渊专属装备资格。前三关依次覆盖打金、护卫与施法挑战，第 4 关起重复挑战终局首领并计层。首关参考 60 秒，后续关次参考 150 秒，接入掉落、失败次数、重试和最高层结算。 |

## 配置交付

以《刀圈TD 6.25 图鉴》和地图脚本为参考。图鉴中的 274 个塔对象含升级与同名变体，243 个物品条目含成装、组件、制作书和道具，另有 90 条具名配方。按实际机制和获取途径逐项核对覆盖范围。升级及外观变体关联到同一条塔成长线。每个有独立玩法的条目保留实现位置或映射说明，首发塔卡和装备数量随配置核对确定。

| 配置 | 内容及现有入口 |
| --- | --- |
| 波次与敌人 | 55 条主线波次，另配打金、主动挑战、无尽普通池、无尽首领池和深渊关次。每条波次指定敌群、时序、奖励与反制，情报读取同一份实际配置。 [波次生成](../game/loop-catalog.js) · [敌方行为](../game/loop-enemy-effects.js) |
| 塔和技能 | 卡池、角色主属性、成长、技能逐级效果、13 项突破条件与橙装资格。用原有效果覆盖普攻、多目标、控制、光环等共用逻辑，为确实不同的技能补结算。 [塔配置](../game/loop-roster.js) · [战斗结算](../game/loop-combat.js) |
| 装备与经济 | 配方记录材料数量、费用和解锁时点。商店与掉落记录来源、库存、刷新和概率。共用购买、合成与穿戴校验，交易失败时资源、槽位及库存保持一致。 [装备配置](../game/loop-equipment.js) · [装备操作](../game/loop-armory.js) |
| 模式与界面 | `createLoopGame()` 继续管理局内状态、时钟与结算。玩法界面完成难度与开局选择、人口和突破提示、商店、未来波次、终局及两种后续模式。2D 和 3D 使用相同的部署和战斗命令。 [对局会话](../game/loop-session.js) · [界面入口](../game/main.js) |

配置阶段回查个人模式的初始资源、活跃出怪口数量、容怪线、抽卡与刷新权重、打金计入规则、部分掉率、同秒投放边界、出售副塔对橙装资格的影响和深渊重试条件。对局数值按已核实的个人模式规则落表。用于《环界》原创敌群和地图的适配数值单独记录依据。

## 模型与表现

已在《环界》的 WebGL 加载器中渲染地图内嵌的经典版 `.mdl`、`.mdx` 和主体 `.blp` 贴图。影魔与众神之王两个样本读出了动作，部分粒子贴图以占位材质显示。原地图还有引用魔兽基础资源的单位，这些单位需要另外提供可用的模型和贴图。

- 按塔、普通怪、首领和特效整理模型清单。记录资源来源、贴图依赖、动作、缩放、朝向与地面偏移。允许使用的模型导入本地模型库，再绑定《环界》的单位或特效 ID。
- 用站立、移动、普攻、施法和死亡逐项验收。核对攻击与命中时点、粒子表现和满场帧率。缺资源或加载失败时使用现有替代外观。
- 公开版使用现有 2D 素材。公开 3D 如纳入后续发布，验收 3D 入口、实际加载和可再分发素材清单。 [本地 3D 运行说明](../game/README.md#循环圈-3d-本地试玩) · [3D 模型加载器](../game/local-3d/model-library.js) · [公开发布构建](../scripts/build-pages.mjs)

## 实施阶段

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 1. 核对规则和内容 | 完整波次、塔技能、装备配方、商店及模式配置表。逐项标出取值依据和待复核参数。 | 55 波连续且可追溯，卡与装备有获取入口，突破目标存在，配方材料可得且无循环依赖。 |
| 2. 跑通前 15 波 | 工人、起手、卡池、部署、人口、经验、前段首领、打金和挑战。接通物理、法术、控制及一条完整配装路线。 | 用正常资源、合法站位和实际操作打过第 15 波，检查第 11 波扩容、挑战入口、打金与跨波容怪。 |
| 3. 完成主线和塔装 | 接齐第 16–55 波、全部塔技及装备，完成第 20 波兑换、突破、高阶商店、妖刀养成与末波结算。 | 至少用物理和法术两种主力阵容各跑完整主线。核对每件装备的实战效果、最后一次打金、终局首领和奖励结算。 |
| 4. 接通无尽和深渊 | 完成分难度的后续入口、模式继承、首领抽取和深渊选塔、重试、掉落与结算。 | 通过无尽首个首领轮及深渊首轮爬层。覆盖模式不开放、超时、重试耗尽、失败与重开。 |
| 5. 完成模型与发行验收 | 更新局内图鉴、商店与情报，验收绑定模型与备用外观。对桌面及触屏执行完整试玩、配置检查和发布构建。 | 桌面和手机均能从开局完成主线并进入对应后续模式。2D 和本地 3D 在同种子、同操作下使用一致的战斗结果。 |

## 最终验收

- 用现有公开对局命令跑多组可复现的随机种子，核对实际出怪、资源账、人口、突破和奖励。每个阶段的实战结果记录种子、关键波次、失败原因与对应修正。
- 覆盖物理、法术和神圣伤害的结算、基础攻击与技能触发顺序、次数盾、先后到期的同类状态、召唤击杀、重复材料、合成失败、装备切换、波次叠加、打金和挑战同场及奖励单次发放。
- 桌面和触屏均通过抽卡、部署、买装、施放、主线通关及后续模式流程。另核对暂停、倍速、切换页面、模型加载失败和重开清理。
- 运行 `npm run typecheck`、`npm test` 和 `npm run build:pages`，按现有试玩清单补齐实测记录。交付可玩的单人游戏、局内图鉴与操作说明。 [试玩清单](../game/qa/manual-checklist.md)
