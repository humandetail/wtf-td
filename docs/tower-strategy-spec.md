日期：2026-11-03。状态：用户已回复“没问题，开始改吧”，本轮已获实现授权；已接入游戏，验证记录见 [交付记录](../game/qa/loop-strategy-delivery.md)。访谈依据见 [tower-strategy-grill.md](tower-strategy-grill.md)，技能数值见 [tower-strategy-balance.md](tower-strategy-balance.md)。已确认规则与设计方拟定的首版参数明确区分；首版经资源约束模拟校准，真机及主观平衡验收仍待用户完成。

## 1. 范围与体验目标

本版只改循环圈。其他六种模式维持已有规则，不自动套用新的伤害、专精、容量或经济。保留所有原素材和历史地图，允许基于现有素材增加技能图形、范围预览、标识和说明。

策略以阵容搭配为核心，资源经营为支撑。保留14塔，分为3种近战、8种远程、3种辅助。近战是路旁短距离攻击设施，不承伤、不挡路、不召唤拦怪单位。位置连续自由，不增加固定塔位。中央逐只随机四向出怪、交叉点随机前进且不掉头的规则保持。

以下为用户最终确认的硬约束：部署科技0—5级的容量依次为 **4／6／8／10／12／16**，所有输出／控制／经济／辅助塔各占一个名额；强化科技0—6级，塔仍最高5级，3级二选一专精，5级标志技能。不得沿用此前建议的20／26／32座容量。

## 2. 塔成长与两种科技

科技两条独立、逐级研究，不设额外波次或另一科技的前置。全局同时仅一项研究，无预排队。付费立即扣款，研究完成才生效；可以全额取消并清空本次进度。科技不占地、不占塔容量。

## 3. 建造、升级、出售与整备

建造每次选定仅建一座，成功退出放置；失败保留预览。造价见数值表，底座占地沿用已有合法性判断。近战最短有效射程也须能从合法路边位置触及道路，不得为实现近战而允许压路。

塔升2／3／4／5级的时间保留5／8／12／16游戏秒。升至目标等级的基础费用依次为初始造价P的0.85／1.10／1.40／1.80倍，四舍五入；军需折扣应用后再四舍五入，最低1金币。耗时优惠开始时快照，最大25%，保留两位小数。费用优惠最多20%；中途增建／出售／改选辅助或研究完成不追补退款、不缩短既有任务。不同塔可同时升级；升级不占研究位，不可取消，不可重复升级、出售或重置。原有其他模式的搬迁规则不受本版影响。

出售非升级中的塔，返还该塔实际建造及升级支出70%，向下取整。折扣减少实际支出；重置专精费不计投资，不进入退款。出售立即释放一个容量。建造仍即时完成，必须支付造价；本版不额外加入建造耗时。

重置专精须同时满足：循环圈本局仍在playing、已暂停、场上无活敌、待出怪队列为空，且该塔已完成3级以上升级。初始准备阶段也遵守以上条件；进入无尽后的安全整备同样可用，结算界面不能操作。有敌人时按暂停不能绕过条件。先暂停会冻结出怪倒计时，防止操作过程中意外开波；不提供任意战斗暂停重配。

改选费为ceil(P×30%)，不享受军需折扣。保留等级、位置、真实历史投资及科技效果；不能改选为当前路线，确认失败不扣费。改选无额外等待，清空该塔全部连击、周期计数和未发出的附加攻击，移除旧路线持久区域／光环。已命中的持续伤害自然到期，数值使用施加时快照，不因改选变强。新路线的首次标志技能须完整等待其触发周期，不允许反复改选刷新大招。界面明确费用、两条路线差别及合法时机。

## 4. 自动选敌与技能触发

玩家可逐塔选：默认职责、最强（当前生命＋护盾）、最低生命百分比、最快、护盾优先、支援优先。身份排序只在合法射程内进行，不凭空扩大射程。塔无目标时不蓄积攻击／连击次数。多目标塔先选主目标，其余按同一优先级选择不同目标；同次攻击不得重复击中同一单位，追猎明确的补射例外。

默认：工程／攻坚偏向重甲，微波破障偏向护盾，微波干扰／捕网猎首偏向治疗支援，聚焦偏向最强，追猎偏向最低生命；其他攻击塔按累计路程最远。并列以累计路程最远、再敌人ID最小排序。光环／补给不显示无用的选敌设置。选敌偏好可随时更改；持续锁敌路线在目标仍合法时维持锁定，修改优先级会主动换锁并清空连击。

普通攻击、连锁、溅射、穿透、多重射击是一次攻击周期。每次周期计一次次数，不能按命中目标数累计；持续灼烧、传火、补射、电爆、集束等追加效果不再触发任何攻击计数或二次追加技能。击杀收益仍正常结算，敌人死亡只结算一次。传火／死亡引爆只由本塔首次施加的主灼烧触发，传播灼烧不再传播或引爆。

连击要求同一个主目标连续攻击且中断不超过2倍当前攻击间隔；死亡、超出射程、切换目标、专精重置时清零。周期技能仅在塔有有效目标并实际攻击时累计；补给／纯光环的时间周期按游戏时间推进。升级、研究完成不会重置现有计数或赠送一次立即触发；首次解锁能力从零开始。

## 5. 伤害、护甲与护盾

仅物理、法术两种伤害。火／冰／雷为效果标签，不新增元素免疫。普通敌人物理减伤0，重甲35%，Boss25%；重甲与Boss取最大值，不相加。法术不受物理护甲影响。破甲用百分点扣减，最低降至0，不形成负甲；同类取最强。

一次命中按“伤害与技能倍率 → 满足条件的浸水电弧加成／调校 → 最强易伤 → 物理护甲 → 护盾 → 生命”结算。易伤上限25%；同类取最强，不同来源不相加。浸水电弧加成仅电弧线圈的基础连锁与超载，数值25%；末端电爆不再次享受。其他条件加成乘算，不制造第三类伤害。灼烧同样受护盾和易伤影响，不能穿盾直接扣血。

破盾额外伤害仅作用于护盾。若护盾S、正常伤害D、破盾倍率M，先用min(D,S/M)份基础伤害消耗护盾；剩余基础伤害扣生命，额外盾伤不得溢出到生命。例：盾50、D40、M2，消耗25份基础伤害破盾，余15伤生命；不会把80减50后的30计入生命。一个伤害事件先完成两段，再结算死亡。

同类灼烧的各来源独立计时，只有当前最强DPS来源造成伤害，不累加；强来源到期后回退到仍存续的次强来源。击杀触发归属当前有效来源，DPS相同时采用较早生效来源。浸水与灼烧共存；治疗只恢复生命，不恢复护盾，不能超过生命上限，不能复活。治疗抑制最高75%，同类取最强。

## 6. 控制与辅助叠加

同类减速、破甲、易伤、攻速光环、射程光环、军需费用／时间优惠取最强，各自保存来源与到期时间；强来源结束后重新取仍有效的次强来源，不能因删除一塔清空其他来源。不同功能可并存。普通减速最大60%；硬控定身期间不能移动，仍可治疗或受伤，除非技能明确抑制治疗。

Boss硬控时长先减半，结束后3秒免疫定身／冻结；免疫内的新硬控不延长或排队，原有伤害／减速照常施加。多个同时生效硬控只采用最长结束时间，不能在受控期间续控。硬控结束时才开始免疫计时。Boss减速取普通效果一半，故上限30%，且解冻后的寒缓仍按此减半。普通敌人无Boss保护，若持续硬控导致阵容近乎无限拖延，按验收调整控制时长／触发间隔，不私加免疫种类。

辅助范围按中心距离判断；只作用于输出／控制塔，不增益自身或其他辅助，避免支援循环。雷达射程不扩大另一雷达或维修／补给范围。军需优惠作用于区域内输出／控制塔的升级，不改变辅助塔自身升级费／时间；经贸与军需互斥。标定与猎首标记归入同类易伤，取强不叠加。距离增益不叠加额外百分比与平值来源，以最高总射程增益计算。

## 7. 敌人、出怪与情报

保留现有12种敌人素材、20波及5／10／15／20波Boss。普通敌人至少有基础、重甲、护盾、快速群体和治疗支援职责。具体波次配比、生命／速度／护盾／治疗见数值表。未来两波在开局即可见：类型、特性、约数（首版显示普通怪精确总数）、Boss能力；不显示四向出生结果或路口随机选择。情报必须来自实际出怪配置，不能用独立文案伪造。

初始金币600，首波30秒。普通模式每波开始后安排下一波：第1—4波后等40秒，第5—9波后等36秒，第10—19波后等30秒；不等待清场，逐只投放仍0.65秒，普通怪仍10+2w只。正常未提前开波时，第10波在370游戏秒开始。每个常规波次全部投入且该波所有敌人（含Boss）被击杀后，单独补给60金币，仅一次；与全场是否还有其他波敌人无关。无尽不发清波补给。手动提前出怪仅当当前队列为空、未暂停、尚未到最终波时有效，不要求清场，不发额外金币。未来波数不足2时只显示剩余实际波。无尽使用本节新增的递增规则生成实际波次，并据此给出接下来两波情报，不把常规波次循环误作数值重置。

容怪60，达到即失败；怪物沿环路持续存在，不按一圈扣命或自动消失。第20波全部投入且清完残敌才通关；结算冻结研究、升塔、持续效果和产金，进入无尽继续剩余时间；失败停止，重开清空。所有计时使用同一游戏时间，暂停／菜单冻结，1／2／3倍速同步。不存在依赖真实时间离线生产或研究。

### 7.1 无尽递增与低收益经济（用户补充）

硬约束：无尽每一波都必须提高实际难度，不能循环相同数值；无尽普通怪、精英、Boss击杀均只发1金币。补给产金必须显著下调，并且不能通过多建补给绕过无尽资源压力。常规1—20波仍按常规奖励，切入无尽不追回已得金币、不清空现有塔、科技或任务。

按用户最新修正，无尽每波固定 **50只，包含Boss**。非Boss波为50只普通怪，Boss波为49只普通怪＋1只Boss；Boss替换一个普通名额，不额外增加总数。每5波出现Boss，无尽自动波次间隔维持26游戏秒、逐只0.65秒。

以下更缓增长为Q23设计委托下拟定的首版参数，待实现后的资源模拟校准：令n=w−20，从第21波的n=1开始，生命／普通护盾倍率为 **4.04×(1+0.01n)**（4.04是常规第20波基准）；每波只增加该基准的1%，采用线性增长，不复利。相对第20波，第21／30／50／100波分别为1.01／1.10／1.30／1.80倍。Boss继续在对应生命上×10。取消此前额外移速增长，各类怪保持自身基础移速，Boss仍按原0.72系数。数量与速度不随无尽波数上升，仅生命／护盾温和递增；伤害类型、物理减伤和硬控保护不变。

普通类型按常规11—20波配比循环，但属性使用当前无尽波序重新计算；不能重用对应常规波次的生命、盾量和奖励。Boss从第25波开始，每5波替换一个普通名额，具备第20波的护盾／自愈能力，其生命也按当前波序增长。治疗数值按实际最大生命计算，因此不能单独沿用常规治疗量。情报显示固定50只总数、Boss是否占其中一席、当前生命成长和实际Boss能力。

奖励由敌人出生所属阶段确定。无尽生成的敌人即使由灼烧、传火、附加技能杀死，奖励也只能为1，不受种类奖励、Boss倍率、补给专精或击杀来源加成影响。一次死亡仍只结算一次；不得再按清场、提前开波或Boss击杀额外发金币。

**无尽补给首版**：所有等级基础产金改为每20秒1金币；经贸3级将该周期收益改为2，强化科技5后改为3。经贸5级分红改为每60秒1金币，强化科技6后改为每45秒1金币。军需路线的升级折扣／耗时优惠保留，基础产金仍每20秒1金币。以上覆盖常规12—28金币／8秒、额外8／10金币及30／40金币分红，不能叠加常规表。

此外，全场所有补给的周期收入和分红合计，不得超过 **floor(无尽累计击杀金币×10%)**。这是全场共用上限，不是每塔各10%。记无尽击杀收入K、已发补给收入S，每次应发r时仅发min(r,max(0,floor(K×0.1)−S))；未能发放部分直接丢弃，不形成欠账、不补发，不转化为其他资源。金币和分红均为整数。多塔同帧请求按轮转顺序分配可用额度，以避免固定ID长期独占。

进入无尽时K、S从0计数，所有补给产金／分红计时从完整新周期开始，不能带常规产金进度或分红余额跨阶段套现；其他研究／塔升级计时仍保留剩余时间。全场没有活敌时补给产金／分红计时冻结，不在暂停、菜单、结算或安全整备期产金。尚未消耗的比例额度可保留，但总额度受K约束，不能通过等待无限刷钱。重开清空计数；无尽中的出售／重置／退款不增加K。出售返还真实投资不是击杀奖励，沿用原规则且不能重复领取。

玩家需要提前看到“无尽：每怪1金币，补给减产且全场限额10%”。补给面板显示当前无尽周期收益、共用剩余额度以及未发放原因；不要让界面仍展示常规高收入。进入无尽后的极限目标是尽量坚持更高波，不承诺可以靠挂机把科技和16座塔全部升满。

## 8. 手机与反馈

## 9. 阵容示例与机会成本

- 物理攻坚：工程碎甲＋自动炮狙猎／榴弹攻坚＋维修调校。依赖破甲覆盖，分散高速怪需补范围控制和多目标火力。
- 法术清群：水炮潮涌＋电弧跳弧＋冷喷广域。依赖敌人聚集与路口几何，对孤立Boss需聚焦／焚心补位。
- 狙杀支援：捕网猎首＋激光聚焦＋微波干扰。减少治疗链收益，面对大量低血敌人可能清理不足。
- 经济转型：前期投入补给，经贸提高长期金币；军需让后期少量核心更快成型。补给占容量且无输出，积怪压力高时必须推迟投资或出售。

阵容是用途示例，不承诺某套必胜。16座是上限而非通关必须铺满；低容量高科技和高容量低等级应各有可行时间窗口。

## 10. 验收及平衡门槛

逻辑自动检查至少覆盖：科技0—5容量精确；两条科技最终等级及前置；三升专精原子交易；升级旧等级战斗／完成时生效；军需费用时间快照；所有14塔两条分支及科技5／6确实影响实际战斗；优先级只在合法射程选择；连锁／穿透／多重不重复计数；追加伤害不递归；死亡只发一次金币；破盾溢出算例；同类取强及来源结束回退；Boss续控及免疫；治疗不能复活；重置时机／计数清理／30%费／70%出售；暂停／倍速／菜单／结算／无尽／重开；其他六种模式不回归。

模拟必须使用实际金币、科技耗时、可放置位置与容量，不注入无限资源。至少10个固定随机种子，报告波次、峰值积怪、金币流、研究／塔投资、获胜／失败。至少两种机制不同的混合阵容在其中8个种子通过20波；不以一种队伍证明平衡。单类塔压力测试至少遇到一个与其短板对应的明显瓶颈，但不要求通过人为硬免疫保证其必败。关键威胁至少两种可购买解法，某一三级分支在针对性场景中应优于另一条，另一场景能反转优势。

经济表逐项核算收入与支出；常规通关不要求研究全满、铺满16座或所有塔5级；无尽继承已有积累，但每怪1金币且补给受限，不承诺最终一定研究全满。供给塔回本时间／军需折扣节省与占用的火力名额一起评估；不能靠重置、折扣或出售产钱。初稿未通过这些验证前，不能声称数值已经平衡。

无尽额外检查：第21／22／30／50／100波普通怪与Boss的实际生命／盾量逐波增长，跨越配比循环也不回落；每波总数严格50（Boss替换普通名额）、无额外移速成长；任意击杀来源均固定1金币，无Boss额外奖；单塔／多塔／分红共用补给10%上限；无击杀无额度、额度不足不记欠账、进入无尽重置产金计时、常规收入不受影响、暂停／结算／无怪时不产金。至少比较0／1／3座补给的实际坚持波数和金币贡献，若多补给在牺牲火力后仍成为唯一最优方案，继续下调产量或上限，不能只凭10%认定平衡。

## 实现期校准记录
