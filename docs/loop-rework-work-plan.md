# 环界循环圈改版工作计划

2026-11-18 · 实施前计划

改版目标是让玩家通过三选一抽卡组阵容、在环路上靠击杀养塔，再用装备补足打法。交付范围包括 **36 张塔卡、58 种怪物、20 波常规关、无尽轮替、主动挑战和金币福利波**，以及这些内容在桌面和手机上的完整操作与展示。塔卡、敌人、技能和波次以[塔卡与怪物设计](loop-towers-and-enemies.md)为内容主表。

当前工作区已有未接通的图纸与单槽装备草稿。实施时按差异逐项收口，由三选一卡包及三槽装备接管对应入口，保留已有有效改动。当前旧玩法基线已通过类型检查和 194 项测试，其结果用于比较后续改版。测试中针对循环圈旧科技、手动升塔和专精的断言，按新规则迁移。其余六种模式继续使用各自的规则和入口。

## 一、玩法基准

| 系统 | 首轮实现口径 |
| --- | --- |
| 抽卡与卡包 | 开局 450 金币，四种普通输出塔内免费三选一。之后每次 150 金币，至少一张普通，三张候选塔种互异。候选在选定前保留。选中即进卡包，可跨波留存、建造或出售；部署免费，成功才消耗卡。付费卡或其对应塔回收 75 金币，起手卡回收 0。允许同名多座。 |
| 品质概率 | 付费候选先抽 1 张普通，剩余 2 张各自按阶段抽品质。普通／稀有／史诗概率从开局的 80／20／0%，经第 5 波 Boss 后的 65／30／5%、第 10 波 Boss 后的 50／37／13%，到第 15 波 Boss 后的 40／40／20%。同品质在该组尚未出现的塔种里等概率选取。 |
| 人口与经验 | 三档品质占 1／2／3 人口。容量开局 4，击杀第 5／10／15 波 Boss 后依次扩至 6／8／10，进入无尽后为 12。击杀给死亡点 260 范围内全部已部署塔的全额经验，含辅助。经验到达 10／30／70／130 自动升级，3、5 级自动解锁固定技能。循环圈取消部署／强化科技、金币升塔和手选专精。 |
| 装备 | 每塔 3 槽。增幅核心、调速齿轮、约束线圈、增程阵列各 80 金币。两组件加 60 金币合成散射火控、破阵弹头、滞行力场、协同枢纽之一，按配方消费实物。支持背包内合成，或同塔两槽原地合成。装空槽和原地合成可在战斗中操作。单塔脱战 5 游戏秒后可卸装或出售带装塔，出售时装备退到背包。 |
| 常规与无尽 | 使用现有环路和合法落点，常规 20 波，第 5／10／15／20 波打 Boss。60 只积怪即失败，限额召唤物和挑战怪计入，金币怪单独计分。无尽从第 21 波开始，预定每波 50 只，Boss 占其中一席，12 个 Boss 按内容主表轮替。无尽继承当前塔、卡、装备、经验与金币，重开清空本局进度。 |
| 挑战与打金 | 8 种挑战按波开放，主动开启、独立投放、28 游戏秒结算，成功发固定奖励。4 类金币怪在对应常规 Boss 击杀后入队，18 游戏秒结算，按实际生命伤害发金币并封顶。第 20 波清完后结算阶段等待 G04 完成，详见内容主表。 |

抽卡、经验、掉落和售卖都需记入可对账的本局记录。击杀归属沿用出生波次，清波补给必须等该波预定投放与召唤物都已解决。开局金币、成长速度、怪物强度和奖金是首轮平衡参数。

### 装备配方

| 成装 | 组件，另付 60 金币 | 成装效果 |
| --- | --- | --- |
| 散射火控 | 增幅核心＋调速齿轮 | 攻击与灼烧伤害 +10%，攻击频率 +10%，已有多目标普攻的独立目标上限 +1。 |
| 破阵弹头 | 增幅核心＋增程阵列 | 射程 +10%，攻击与灼烧伤害 +10%，对 Boss 的直接伤害再 +25%。 |
| 滞行力场 | 约束线圈＋增程阵列 | 射程 +10%，主动施加的减速、定身与冻结持续时间 +35%。 |
| 协同枢纽 | 调速齿轮＋增程阵列 | 雷达和维修的作用半径 +20%，主动支援技能周期缩短 15%。 |

组件单独装配时，核心给攻击与灼烧伤害 +10%，齿轮给攻击频率 +10%，线圈给主动控制持续时间 +15%，阵列给攻击射程或有效辅助作用半径 +10%。同一塔限一件同名装备，同属性的装备加成取最高值。装备面板显示适用塔、槽位、配方库存和当前脱战剩余秒数。

## 二、交付顺序

| 阶段 | 前置 | 要完成的工作 | 阶段验收 |
| --- | --- | --- | --- |
| 0. 锁定规则和内容 | 当前设计稿 | 核对 36 张塔卡、58 种怪物和 20 波配表；为卡、技能、怪物、装备和素材锁定稳定 ID；明确现有草稿与旧循环圈的替换范围；保存旧版本测试和试玩基线。 | 牌池概率、人数、波次数量、首次出场、成长和奖励可逐项对账。实现任务能引用明确的规则项。 |
| 1. 跑通前五波 | 阶段 0 | 打通免费起手、付费抽卡、选牌、卡包、放塔、回收、击杀经验、自动学技能与 Boss 扩容。先接入起手塔、前五波敌群和破阵山魈，沿用现有地图和放置几何。 | 桌面和手机都能按真实操作从开局打完第 5 波。模拟使用默认金币和合法站位，抽牌和出怪分别可通过种子复现。 |
| 2. 补齐战斗内容 | 阶段 1 | 先完善公用命中和状态结算，再分批接入物理塔、法术／控制塔、辅助塔。接入 24 种普通怪、10 种精英、12 个 Boss，完成第 1–20 波和无尽表。 | 36 塔的 1／3／5 级行为都可观察。护盾、次数盾、隐匿、抑疗、打断、净化、召唤和 Boss 阶段技均用实际战斗验证。正常流程可从第 20 波进入无尽并走完整个 Boss 首轮。 |
| 3. 接入装备系统 | 阶段 1 的经济与塔身份，阶段 2 的结算接口 | 接入组件商店、四种成装、背包和三槽装备。把伤害、攻速、射程、控制和支援效果接入实际战斗，按有效攻击、持续伤害、控制及实际支援记录脱战。 | 资金、材料、槽位更新一次完成。可退回装备，暂停和倍速行为正确，卸装和出售带装塔遵守 5 秒脱战。显示数值与实战结算一致。 |
| 4. 接入挑战与金币怪 | 阶段 2、3 | 实现独立投放、入口预告、开放条件、计时与结算。加入金币优先、实际扣血计分、奖金上限及第 20 波转场。 | 同时有常规敌人、挑战目标和金币怪时，投放、容怪、目标优先级、计时、金币和经验分别正确。能复现挑战成功、超时、失败和完整奖励队列。 |
| 5. 完成界面、模型与特效 | 阶段 0 后可启动原画；阶段 2–4 后整体验收 | 完成抽卡、卡包、装备、预告、挑战、打金和结算界面。按模型清单交付正式素材，补齐战斗提示、移动和攻击表现、音效及图鉴。 | 所有单位都有可用正式模型，关键机制在正常缩放、重叠怪群和手机视图能识别。资源失败可恢复，地图在开关面板前后保持同一视野。 |
| 6. 平衡与发行验收 | 阶段 1–5 | 进行多种子对局、实机整局试玩、压力测试和其他六模式回归。校准实际能组出的阵容、Boss 战、挑战奖励、打金上限与无尽压力，整理发行记录。 | 自动检查、发行构建及代表性完整对局通过。实机试玩记录区分自动验证与人工结论。按现有 GitHub Pages 流程准备发行。 |

阶段 1 的内部试玩使用已接通的候选池，正式候选在阶段 2 完整启用。阶段 2 先做命中、击杀、经验与波次收尾，然后做护盾／叠加／读条，再做群控、转向、召唤与对塔减益。前五波完成后即可试玩，正式美术和后期波次继续推进。

## 三、实现与验收要点

- **规则边界。** 循环圈会话拥有卡包、塔经验、装备、挑战、福利与无尽状态。沿用现有道路、放置校验、输入、渲染和事件通路。目录为塔卡、敌人、波次和装备提供事实来源，预告、图鉴、按钮报价和战斗读取同一份数据。
- **交易。** 验证金币恰好够、人口已满、候选未选、卡仍在包里、取消放置和连续触碰。非法落点保留卡。一次成功操作只消耗一次金币、卡或组件。待选和背包可以跨波，进无尽继承，重开重置。模拟记录每笔收入和支出，并与状态金币对账。
- **战斗。** 验证辅助经验和连跳升级、持续伤害与追加攻击击杀只结算一次。伤害与击杀派生效果应有明确处理顺序。防御盾、隐匿、免疫、打断与同类效果叠加分别用生产会话跑场景。检查分裂先移除母体、子体计容量、全部清完才发补给。
- **时间与终局。** 检查同一次更新内触发多事件、暂停、1／2／3 倍速、挑战超时、G04 结算和无尽衔接。验证耗尽奖励、挑战伴生怪、金币怪的过量伤害、补给产金限额。快进跨过多个波次时，终局只进入一次。
- **配阵与数值。** 固定物理、法术两种按职责选牌的策略，各跑至少 10 个可复现种子，每组目标至少 8 局通关，再验证一局禁用史诗仍可通关。记录第 5／10／15／20 波的阵容、等级、峰值积怪、经济与击杀耗时。比较挑战开与关、打金优先与常规优先。先调首领有效生命和塔成长，再调人口、抽卡概率与奖金。无尽至少走过一轮 12 个 Boss，并验证第 85 波回到 B05。
- **界面与发行构建。** 用实际桌面鼠标和手机触控完成抽卡、部署、卖塔、购买／合成／卸装、开挑战、福利与无尽。检查小屏、横屏、缩放和拖拽，及预告和战场实际数量的一致性。交付前运行 `npm run typecheck`、`npm test`、`npm run build:pages`，用发布包路径打开游戏检查所有新资源。

## 四、模型与资源交付

塔卡完整清单为原有 14 座加新增 22 座。原有模型作为现有单位的资产来源，新增塔可以独立设计模型。怪物表已建议 **32 种独立新模型**，其余可直接复用或制作变体。成对单位共享骨架、皮肤和方向素材的选择在资产登记时确定。

| 批次 | 模型和特效 | 出口 |
| --- | --- | --- |
| A. 前五波样板 | 起手塔和首次新怪铁砂蠕虫，破阵山魈、第一批盾图标、第一套挑战与金币怪外观样板。 | 确认地图实景下的单位比例、底座位置、转向、配色、攻击提示与血条锚点。一个样板可进入发布包并在手机上辨识。 |
| B. 常规关主体 | 1–20 波的普通怪、精英、4 个常规 Boss，以及主线常用新增塔。优先分清重甲、隐匿、护卫、两种护盾、读条和召唤。 | 实际通关路线里每个新对象都有正式模型和机制提示，四个 Boss 剪影及蓄力动作分开识别。 |
| C. 无尽与特殊内容 | 8 个无尽新 Boss、8 种挑战怪、4 类金币怪，以及其余新塔。补齐发光、状态变化、特殊攻击、挑战和金币窗口的音效提示。 | 全图鉴可遍历。无尽、挑战、打金均核对正式绘制、单位辨识与性能。 |

每条素材记录设计 ID、原图或可编辑源、运行文件、方向帧、底部锚点、缩放与关键动作。战斗几何来自规则配置。新资源纳入运行清单和发布白名单，原素材继续按现有哈希校验。用相同设备对比改版前后首载和高密度场景，先处理资源体积和帧率退化再进入发行验收。

## 五、最终交付与边界

最终交付包含可玩循环圈、完整图鉴和正式资源、验证报告及发行包。报告附上种子、对局记录、账本、实机检查结果和数值校准记录。既有循环圈科技与专精文档作为旧版规则保留，改版完成时更新实际玩法入口、帮助与验收清单。发布使用现有项目的发行流程，具体推送与上线以发布请求为准。
