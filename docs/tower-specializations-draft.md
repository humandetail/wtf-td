# 循环圈14塔技能与专精草案

状态：第五轮已确认14塔基础职责及两条专精方向；尚非完整实现规格。具体结算、参数及验收仍待确认。不改原素材，其他模式不直接套用。

基础职责在1级成立，2级强化基础；以下每条路线用“3级能力 → 5级标志技能”表示，4级强化所选路线。两条路线不兼得。名称为功能工作名。

| 塔／基础职责 | A路线：3级 → 5级 | B路线：3级 → 5级 | 主要短板 |
| --- | --- | --- | --- |
| 工程震荡／近战物理，短范围破甲 | 碎甲：强化单体破甲 → 连续敲击同一目标触发重击 | 扫荡：每次震击多个目标 → 周期释放范围破甲震波 | 覆盖距离短，自身输出有限 |
| 冷却喷射／近战法术，扇形减速 | 深寒：持续喷射积累冻结 → 解冻后保留寒缓 | 广域：扇面扩大、覆盖更多敌人 → 周期留下短时减速区 | 单体输出低，控场不等于击杀 |
| 电弧线圈／近战法术，近邻连锁 | 跳弧：增加跳跃目标 → 连锁末端释放小范围电爆 | 电容：减少跳跃、强化连续打击 → 同目标累计命中后超载 | 跳弧依赖敌人聚集；电容清群弱 |
| 自动拦截炮／远程物理，快速单体 | 狙猎：持续锁敌叠伤 → 连击触发单体穿甲弹 | 分流：升级解锁三目标射击 → 五目标射击 | 分流分摊单体火力，狙猎怕频繁换目标 |
| 重型榴弹炮／远程物理，慢速溅射 | 爆破：扩大爆心清群 → 周期集束弹 | 攻坚：缩小爆区、强化重甲伤害 → 连续命中触发破甲重炮 | 慢攻速，爆破对孤立强敌效率低 |
| 激光跟踪／远程法术，远距单体 | 聚焦：持续照射同目标增伤 → 达到阈值触发过载束 | 贯穿：升级解锁直线穿透 → 增加穿透目标上限 | 聚焦换目标重置；贯穿依赖道路几何位置 |
| 高压水炮／远程物理，小范围攻击并施加浸水 | 水牢：强化范围减速 → 周期短暂束缚爆心目标 | 潮涌：扩大浸水覆盖 → 周期扩散浸水水环 | 无长时间硬控，依赖伤害塔配合 |
| 微波干扰／远程法术，额外护盾伤害 | 破障：集中破盾 → 破盾后该目标短时易伤 | 干扰：降低支援怪治疗效率 → 周期抑制区域治疗 | 无盾无治疗时输出效率较低 |
| 捕获网／远程物理，低伤单体定身 | 猎首：优先支援敌人并延长单体控制 → 定身目标受到集火标记 | 群缚：升级解锁多目标捕网 → 周期范围撒网 | 硬控受Boss规则限制，不能替代输出 |
| 符焰法塔／远程法术，持续灼烧 | 焚心：强化单体灼烧 → 持续灼烧同目标触发爆燃 | 传火：灼烧目标死亡传火 → 死亡小范围引爆 | 持续伤害起效慢，传火依赖击杀 |
| 三联追击／远程物理，基础三个独立目标 | 弹幕：五目标 → 七目标 | 追猎：补射低血量目标 → 击杀缩短下次攻击等待 | 弹幕单目标弱；追猎低血条件不满足时收益有限 |
| 雷达哨站／辅助，为附近塔增加射程 | 标定：标记敌人使其受伤增加 → 提高对精英及Boss标记效果 | 组网：强化附近塔射程 → 周期给予范围内塔短时射程增益 | 占塔容量，收益依赖输出塔布局 |
| 维修机械臂／辅助，提高附近塔攻速 | 超频：强化附近塔攻速 → 周期短时超频 | 调校：附近塔对重甲和护盾目标伤害提高 → 周期强化下一次攻击 | 无独立输出，同类增益叠加待定 |
| 无人机补给／辅助，定时产金币 | 经贸：增加周期收益 → 连续存续取得额外分红 | 军需：附近塔升级费用降低 → 缩短附近塔升级耗时 | 占容量和初期金币，不能直接处理敌人 |
